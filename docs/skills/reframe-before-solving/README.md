# 스킬 제안: reframe-before-solving

마음에 들면 쓰세요. 이 저장소에 자동으로 켜지지 않습니다.

## 무엇을 하나

예시나 떠올린 해결책을 보여 주며 기획·설계를 요청하면, Claude가 그 예시를 전체 요구로 좁혀 받아들이기 쉽습니다. 이 스킬은 답을 좁히기 전에 실제 목표, 예시에서 꼭 지킬 점과 우연히 그렇게 된 점, 다른 접근을 먼저 보게 합니다. 그다음 선택을 떠넘기지 않고 하나를 추천하게 합니다.

핵심 규칙은 "넓게 생각하되, 일을 크게 만들지는 않는다"입니다. 맞춤법 수정이나 이미 합의한 계획 실행처럼 정확한 요청에는 끼어들지 않습니다. 사용자가 이유와 함께 못 박은 제약(예: 게재 규격상 세로 2컷 필수)도 바꾸자고 하지 않습니다.

## 왜 만들었나

S14~S17 밈 작업에서 같은 실수가 반복됐습니다.

- 2컷 예시 하나를 보고 모든 밈을 2컷으로 고정했습니다.
- "임의 캐릭터 쓰지 마"를 "참조를 받을 때까지 멈춰"로 읽었습니다.
- "본문이 심심하다"는 말에 장식만 더했습니다.

## 설치

개인 스킬 폴더에 복사하면 모든 프로젝트에서 쓸 수 있습니다.

```
mkdir -p ~/.claude/skills/reframe-before-solving
cp docs/skills/reframe-before-solving/SKILL.md ~/.claude/skills/reframe-before-solving/
```

새 Claude Code 세션부터 스킬 목록에 보입니다. 지우려면 그 폴더를 삭제하세요.

## 확인한 것 (2026-10-22)

| 요청 | 스킬 없을 때 | 스킬 있을 때 |
|---|---|---|
| "이 2컷 예시처럼 캐릭터 밈을 자동으로 만들고 싶어" | 2컷 포맷 하나로 고정하고 결정 3가지를 사용자에게 넘김 | 2컷을 참고 형식으로 보고 소재에 맞는 포맷을 고르는 방향을 추천 |
| "고객 문의를 줄이려고 챗봇을 만들고 싶어" | 이미 문의 분류부터 권함 | 목표와 수단을 먼저 나누고, 챗봇을 빼지 않고 자리를 정함 |
| "게재 규격 때문에 반드시 세로 2컷" | 2컷은 지켰으나 선택을 넘김 | 2컷 안에서 추천안 하나와 대안 |
| "맞춤법만 고쳐 줘" | - | 적용하지 않고 바로 고침 |

새 세션에서 스킬 이름 없이 요청했을 때 첫 두 요청에서는 스스로 호출됐고, 맞춤법 수정에서는 호출되지 않았습니다. 요청마다 한 번씩만 확인했습니다.
