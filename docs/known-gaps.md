## 3. 품질·기능 (중간)

| 빈틈 | 설명 |
|---|---|
| 구글 트렌드 쓸모 적음 | 전체 인기 검색어(스포츠·연예 등)라 틈새 주제(예: 치이카와)와 거의 맞지 않는다. 비용은 거의 없지만 관련 자료로 남는 일이 드물다 |
| 네이버 블로그 결과는 후기가 많음 | 블로그 검색 결과는 방문·구매 후기가 많아 대부분 걸러진다. 실제 자료는 주로 뉴스에서 나온다 |
| 자료 작성일을 모름 | 네이버 검색 결과에 작성일이 늘 보이지 않아 자료마다 작성일을 기록하지 못한다. 대신 검색을 최신순·최근 1주로 걸고(ADR 0032), 원고에 수집일을 알려 준다 |
| 원고는 하루 한 번 | 첫 활동 시간 시작 50분 뒤에 한 번 만든다. 낮에 더 만들려면 대시보드에서 "원고 만들기"를 누른다 |
| 설정 변경은 새 원고부터 | 페르소나·브랜드를 바꿔도 이미 만든 원고(검토 대기 포함)는 그대로다. 필요하면 폐기하고 다시 만든다 |
| 이미지 생성 꺼둠 | AI 배경 이미지는 유료라 기본값이 `image_generation: off`다(ADR 0036). 카드 배경은 코드로 그린 그라디언트·도형·캐릭터이고, 주제에 맞는 사진은 검토 화면에서 직접 올린다 |
| 인스타 댓글 숨기기 없음 | 인스타그램 웹에 숨기기 메뉴가 없어 스팸은 사람 검토로 넘어간다(스레드는 자동 숨김) |
| 인스타그램 답글 확인 | 답글이 댓글 아래에 달리면 "답글 N개"로 접혀 보인다. 프로그램은 그 숫자가 늘었는지로 확인한다(C22). 확인에 실패하면 다시 보내지 않고(이미 나갔을 수 있음) "확인 필요"로 사람에게 넘긴다(C23). 2026-10-19 사례: "게시"를 마우스로 누르면 초점이 빠져 답글 대상이 지워지는 경쟁이 있어 새 댓글이 되거나(확인 실패로 기록) 답글이 됐다 → Enter 전송으로 바꿈(C25) |
| 댓글은 첫 화면까지만 | 게시물 화면 첫 페이지에 보이는 댓글까지 읽는다. 댓글이 아주 많은 글은 일부를 놓칠 수 있다 |
| 인스타 댓글은 30분마다·최근 3일 글만 | 글 페이지를 하나씩 열면 요청 제한(HTTP 429)에 걸려 드물게 본다(ADR 0038). 자동 답이 최대 30분 늦고, 3일보다 오래된 글의 새 댓글은 인스타그램에서 직접 본다 |
| 게시 시간 최적화 없음 | 게시 시간은 사람이 정한다. 시간대별 성과로 자동 조정하지 않는다 |
| 설정 화면에 없는 값 | 수집 건수(`collect.per_source_limit`), 관련성 기준(`relevance_threshold`), 재시도 간격 등은 `config.yaml`에서만 바꾼다. 드라이런·계정·키·보호 모드는 일부러 뺐다(ADR 0028) |

## 4. 알고 쓰면 되는 것 (낮음)

| 항목 | 설명 |
|---|---|
| 네이버 블로그 게시 안 함 | MVP 범위에서 뺐다(ADR 0016). 네이버는 자료 수집에만 쓴다 |
| Windows 전용 | 자동 시작·알림·키 보관이 Windows 기준이다 |
| 대시보드 로그인 없음 | 127.0.0.1(내 PC)에서만 열리고 저장마다 CSRF 토큰을 확인한다. 같은 PC를 쓰는 다른 사람은 열 수 있다 |
| 백업은 같은 PC 안에만 | 매일 `%USERPROFILE%\.nsm\backups\`에 최근 7개를 남긴다(C12). PC 디스크가 고장 나면 백업도 같이 사라지니, 중요하면 가끔 다른 곳(USB·클라우드)에 복사한다 |
| 실계정 계약 테스트 | `-m contract` 테스트는 운영 계정(@nonsleepmarketer)에 실제로 올렸다가 지운다. 그 사이 팔로워에게 보일 수 있어 실행 전에 알린다 |
| 밈 그림은 다음 배치(S14 제안) | 밈 원고는 대본까지만 만들고 컷 그림은 S15 제작 파이프라인이 채운다. 그 전엔 "그림 없음" 자리이며 게시로 보낼 수 없다 |
| 밈 중복 판정은 토큰 기준 | 번역·의미 비교 없이 조사 제거 토큰 겹침 + 대비 구조로만 같은 농담을 잡는다. 표현이 완전히 다른 같은 농담은 통과할 수 있다(검토자가 본다) |
| 미확인 과금 요청(S13 제안) | OpenAI 요청이 서버에 닿은 뒤 응답을 못 받으면 생성·과금 여부를 알 수 없어 "미확인"으로 남기고 예약액만 상한에 잡는다. 서버 쪽 결과 조회 경로가 없어 사람이 풀어야 한다(S15 화면) |
| 작업 공간과 미디어 폴더 | 비용·원고·슬롯은 프리셋 DB에 남지만 `media/`·`uploads/`는 전역 폴더다. 파일은 원고 id로 귀속되므로 섞이지 않지만, 프리셋을 지워도 그 원고의 파일은 남는다 |
| OpenAI 캐시 할인 미반영 | Responses 캐시 입력 할인은 비용에 반영하지 않는다(보수적으로 정가) |
| `nsm run` 중 설정 파일 직접 수정 | 켜진 상태에서 `config.yaml`을 고치면, 설정 화면에서 저장할 때 실행 중인 값으로 덮어쓴다. 파일은 끈 뒤에 고친다 |
