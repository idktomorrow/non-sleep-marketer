# 0018. 플랫폼 capability: 스레드는 댓글 숨기기 지원, 인스타그램은 미지원

- 상태: 제안 (배치 B 반영) · 날짜: 2026-10-13 · 관련: [day1-verification](../day1-verification.md), [contracts.md](../contracts.md) 4절, 이슈 #14

## 배경

어댑터는 자기가 할 수 있는 일(capability)을 선언하고, 댓글 정책은 그에 맞춰 스팸을 숨기거나 사람에게 넘긴다. 1일차 검증에서 PC 웹 댓글 메뉴를 확인했다.

- 스레드: "모두에게 숨기기" 있음
- 인스타그램: 신고·삭제·취소뿐, 숨기기 없음

## 선택지

1. **인스타그램은 숨기기 미지원으로 선언 → 스팸은 사람 검토로**
2. 인스타그램은 숨기기 대신 삭제: 자동으로 처리된다 / 되돌릴 수 없고, 정상 댓글을 스팸으로 잘못 분류하면 사용자의 고객 댓글이 사라진다

## 결정

1번. capability 표를 `nsm/adapters/platforms/__init__.py`의 `PLATFORM_CAPABILITIES` 한 곳에 두고, 드라이런 어댑터와 배치 G의 실계정 어댑터가 함께 쓴다. 드라이런 인스타그램은 숨기기를 호출하면 `NotSupportedError`를 낸다.

## 결과

- 드라이런에서 본 댓글 처리(스팸 → 숨김/넘김)가 실계정과 같아진다.
- 인스타그램 스팸이 많으면 검토 대기열이 늘 수 있다. 그때 "자동 삭제" 옵션을 새 ADR로 검토한다.
- 네이버 블로그는 범위 밖([0016](0016-drop-naver-blog-publishing.md))이고 검증하지 않아 숨기기 미지원으로 둔다.
