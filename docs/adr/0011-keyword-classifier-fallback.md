# 0011. API 키가 없을 때 키워드 분류기로 대체한다

- 상태: 제안 (배치 D1) · 날짜: 2026-10-11 · 관련: [ADR 0003](0003-classifier-jev-and-claude.md), 이슈 #7

## 배경

ADR 0003은 jev(MotherDuck)와 Claude 두 분류기를 정했다. 그런데 처음 설치한 사용자는 키가 하나도 없을 수 있고, 드라이런으로 "일단 돌려 보기"가 막히면 체험이 안 된다. 테스트·CI도 키 없이 돌아야 한다.

## 선택지

1. 키가 없으면 수집 잡을 실패시킨다: 단순 / 첫 체험이 막힘
2. **세 번째 구현으로 무료 키워드 분류기를 둔다**: 관심 주제·브랜드 단어가 들어 있으면 관련, 댓글은 단어 목록으로 6분류

## 결정

2번. `classifier: auto`는 MotherDuck 토큰 → jev, Claude 키 → claude, 둘 다 없으면 keyword 순으로 고른다. 키워드 분류기의 신뢰도는 최대 0.85로 묶어 둔다.

## 결과

- 품질은 낮다. 관련성 0.8 기준을 겨우 넘거나 못 넘는 경우가 많아, 대부분 사람 검토로 간다(보호 모드와 함께 안전 쪽으로 기운다).
- 실제 운영에서는 `nsm doctor`가 Claude 키 없음을 WARN으로 알린다.
- 용도별로 어휘가 달라서 분류기를 `ClassifierSet`(관련성·주제·댓글)으로 묶어 넘긴다. jev·claude는 셋이 같은 객체다.
