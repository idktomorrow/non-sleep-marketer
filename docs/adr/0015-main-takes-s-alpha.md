# 0015. 배치 S-α(카드뉴스 템플릿·렌더러)를 메인이 맡는다

- 상태: 채택(2026-10-13, 배치 B 반영 PR에서 선웅제 확정) · 날짜: 2026-10-12 · 결정: 선웅제 · 관련: 이슈 #18 #19, [process.md](../process.md) 2절, [contracts.md](../contracts.md) 1절

## 배경

S-α(S2 템플릿 3종, S3 렌더러·미리보기 하네스·렌더 테스트)는 서브 담당이었다. 1주차 메인 배치(A~F, H)는 끝났는데 S-α는 착수되지 않았고, 지금 드라이런은 단색 PNG(`PlaceholderRenderer`)로만 돈다. 카드뉴스 이미지는 사용자가 실제로 보는 산출물이라 품질을 일찍 확인해야 다음 결정(실계정 게시 G, 디자인 I)이 가능하다.

## 선택지

1. 서브 착수를 기다린다: 소유권 유지 / 실제 카드 품질 확인이 늦어진다
2. **메인이 S-α를 맡고, 서브는 이후 다듬기(S-γ)와 계약 테스트(S-β)를 맡는다**

## 결정

2번. 이슈 #18·#19 라벨을 `owner:main`으로 바꾼다. 디자인 승인은 메인이 PR 리뷰에서 PNG를 보고 한다.

## 결과

- `nsm/render/`, `nsm/templates/`, `tests/render/`의 소유권은 이번 배치 동안 메인. 머지 후에는 contracts.md 1절대로 서브가 다듬을 수 있다(S-γ).
- 서브의 남은 일: S-β(어댑터 계약 테스트), S-γ(2주차 품질·템플릿 다듬기).
