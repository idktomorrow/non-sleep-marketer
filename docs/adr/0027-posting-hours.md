# 0027. 일은 24시간, 게시는 사람이 깨어 있는 시간에만

- 상태: 채택 (선웅제 결정, 2026-10-13) · 날짜: 2026-10-13 · 관련: [0008](0008-autopublish-guardrails.md)

## 배경

"논슬립 마케터"라는 이름처럼 페르소나 활동 시간을 0~24시로 두고 싶다. 그런데 활동 시간 하나가 수집·생성·게시·답글을 모두 정했다. 수집·생성 시각은 활동 시간 시작(0시)에 맞춰 잡히고(0시 20분 수집, 0시 50분 생성), 게시 잡은 30분마다 돈다. 그래서 자동 게시가 켜지면 하루치 글이 새벽 1~4시에 올라간다. 하루 게시 수는 쿼터(인스타 1, 스레드 2)로 정해져 있어 24시간으로 늘려도 더 올라가지 않고 시각만 바뀐다. 팔로워가 자는 시간이라 노출이 가장 적다.

## 선택지

- A. 전부 24시간: 손댈 것이 없지만 글이 새벽에 올라간다.
- B. 일(수집·생성·댓글 답글)은 활동 시간(24시간), 게시만 따로 정한 게시 시간에.

## 결정

B. `settings.posting_hours`(활동 시간과 같은 형식의 구간 목록)를 추가한다. 게시 잡은 활동 시간 안이면서 게시 시간 안일 때만 움직이고, 아니면 "게시 시간 밖"으로 건너뛴다(`policy.should_post`). 값이 없으면 지금처럼 활동 시간과 같다(기존 설정 호환). 페르소나 모델은 동결 계약이라 설정(`Settings`)에 둔다.

선웅제의 운영 설정: 활동 시간 00:00~23:59, 게시 시간 08:00~23:00.

## 결과

- 밤에 만든 원고는 승인·대기 상태로 있다가 아침 8시 이후 첫 게시 잡에서 올라간다.
- 댓글 답글은 새벽에도 10분마다 돈다(가상인물 표기가 붙은 계정이라 바로 답하는 것이 문제 되지 않는다고 봄).
- 게시 시간을 시간대별 노출 지표로 자동 조정하는 일은 하지 않았다(지표가 쌓이면 주간 리포트에서 볼 것).
