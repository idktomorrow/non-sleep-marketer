# 0075. 폴더 고르기는 브라우저 선택 창 대신 서버가 같은 PC에 Windows 폴더 선택 창을 띄운다

- 상태: 채택
- 날짜: 2026-11-18
- 결정한 사람: 선웅제(배치 C50 요청), 대행 Claude
- 관련: [0074](0074-backup-copy-folder.md), devlog [2026-11-18-batch-C50](../devlog/2026-11-18-batch-C50.md)

## 배경

C49의 "백업 복사 폴더"는 전체 경로를 손으로 넣어야 한다. 브라우저의 폴더 선택(`<input type=file webkitdirectory>`,
File System Access API)은 보안상 페이지에 폴더 이름이나 핸들만 주고 `C:\…` 같은 전체 경로는 주지 않는다. 그래서
브라우저 안에서 고르면 서버가 그 폴더에 쓸 수 없다.

## 선택지

1. **브라우저 선택 창**: 전체 경로를 못 받으니 쓸 수 없다.
2. **서버가 같은 PC에 Windows 선택 창을 띄움**: 대시보드는 127.0.0.1에만 열려 있어(TrustedHost), 버튼을 누른 사람이 곧
   `nsm run`이 도는 PC 앞에 있는 사람이다. PowerShell로 `FolderBrowserDialog`를 띄우고 고른 경로를 돌려받는다.
3. 경로 입력만 두고 사용설명서로 안내(지금 상태).

## 결정

2번. 텍스트 칸은 그대로 두고 버튼은 칸을 채우기만 한다(저장은 사용자가).

- 알림처럼 PowerShell을 `-NoProfile -NonInteractive -EncodedCommand`로 부르고, 선택 창에 필요한 `-STA`를 더한다.
  제목·처음 폴더는 알림과 같은 `ps_literal`(`nsm/adapters/notify/windows.py`)로 작은따옴표 리터럴 안에만 넣는다.
  PowerShell이 따옴표로 보는 `‘’‚‛`도 두 번 쓴다(이 배치 리뷰에서 알림 쪽에도 같은 빈틈이 있어 함께 고쳤다).
- 스크립트는 `$ErrorActionPreference='Stop'`과 try/catch로 감싸, 창을 띄우다 실패하면 "취소"가 아니라 오류(종료 코드 1)로 끝난다.
- `def` 라우트(스레드 풀)에서 돈다. 선택 창을 기다리는 동안 작업 스레드(잡 큐)를 막지 않는다. 300초가 지나면 PowerShell을
  끝내고 "5분 동안 고르지 않아 닫았습니다"를 보여 준다. `nsm run`을 끌 때(Ctrl+C)는 떠 있는 창을 바로 닫아 종료를 붙잡지 않는다.
- 한 번에 창 하나(모듈 잠금, 잡혀 있으면 바로 "이미 떠 있음").
- 결과는 성공·취소·오류 모두 200 JSON으로 돌려준다(화면이 문구를 그대로 보여 줌). 거절은 CSRF 403만.

## 결과

- 사람이 경로를 옮겨 적지 않아도 된다. 동기화 폴더 아래에서 바로 "새 폴더 만들기"도 된다.
- 대시보드를 다른 PC에서 여는 구성이 생기면 창이 서버 PC에 뜬다. 지금은 127.0.0.1 전용이라 그런 경우가 없고, 바뀌면 이 결정을 다시 본다.
- Windows가 아니거나 PowerShell이 없으면 "폴더 선택 창을 열 수 없습니다. 경로를 직접 넣으세요"만 보이고 칸은 그대로 쓴다.

## 포그라운드 잠금 우회 (C51 덧붙임, 2026-11-19)

**문제**: 실제로 쓰니 선택 창이 브라우저 뒤에 떠 Alt+Tab으로 찾아야 했다(작업 표시줄만 깜빡임). 창을 띄우는
`powershell.exe`는 `nsm run`이 낳은 백그라운드 프로세스라, Windows의 포그라운드 잠금(마지막 입력을 받은 프로세스가
아니면 `SetForegroundWindow`를 막음)에 걸린다. C50의 주인 폼은 `TopMost`였지만 `Show()`하지 않아 효과가 없었다.

**결정**: `picker_script` 안의 PowerShell만 바꾼다.

1. 주인 폼을 실제로 띄운다: 테두리 없음·작업 표시줄 없음·`TopMost`·투명(`Opacity 0`)·1×1·**화면 중앙**(`CenterScreen`).
   대화 상자는 주인 폼 위치 기준으로 뜨므로 화면 밖에 두면 대화 상자도 화면 밖으로 간다.
2. `ShowDialog` 직전에 최소화 → 복원 → `Activate()`. 최소화·복원은 포그라운드 잠금에 걸리지 않고 창을 앞으로 가져오는 알려진 방법이다.
3. `ShowDialog`가 끝나면 `finally`에서 주인 폼을 `Close()`·`Dispose()`. 종료 코드는 `$code`에 담아 `finally` 뒤에 한 번만 `exit`.

**확인**: 예시 데이터 데모 서버(`--real-picker`)에서 보이는 브라우저를 앞에 두고 OS 마우스 클릭(SendInput)으로 버튼을 눌렀다.
C50 스크립트는 포그라운드가 브라우저로 남고 z-순서도 브라우저가 위(재현), C51은 포그라운드가 선택 창이고 브라우저 위·화면 중앙.

**넣지 않은 것**: 마지막 수단으로 생각한 Alt 키 한 번 보내기(`SendKeys::SendWait('%')`)는 2번으로 포커스까지 와서 넣지 않았다.
브라우저 메뉴가 열리는 등 부작용이 생길 수 있어, 2번이 실패하는 PC 보고가 오면 그때 직접 확인하고 덧붙인다.
화면의 "보이지 않으면 작업 표시줄을 확인하세요" 안내는 안전망으로 그대로 둔다.
