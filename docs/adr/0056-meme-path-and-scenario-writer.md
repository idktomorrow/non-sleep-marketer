# 0056. 밈 경로: 정보 원고와 분리된 대본 작가(ScenarioWriter)와 밈 규칙 (포트 추가, 합의 필요)

- 상태: 제안 (배치 S14, 서브 제안 PR. `nsm/ports/`에 `ScenarioWriter` 추가 = 동결 변경)
- 날짜: 2026-10-21
- 결정한 사람: 서브(제안 초안). 2026-10-21 사용자 리뷰 반영(숫자 = 사실 주장 아님, claims 허용, 토큰 유사도만으로 버리지 않음, 밈은 말투 옵션이 아님)
- 관련: [0055](0055-deck-comic-sticker-and-per-asset-ai-label.md), [0057](0057-pick-slots-state-machine.md), [0053](0053-workspace-settings-and-run-snapshot.md), [0008](0008-claims-with-source-ids.md)

## 배경

S11의 "밈 말투"는 정보 원고에 드립을 얹는 수준이었다. 레퍼런스의 밈은 캐릭터가 **상황을 연기**하는 2컷(대비 + 반전)이고 뉴스가 없어도 만들 수 있다. 정보 원고의 사실·출처 검증 규칙을 그대로 밈에 걸면 창작 대사가 "출처 없음"으로 막히고, 반대로 밈에 가짜 출처가 붙으면 안 된다.

## 선택지

1. **TextGenerator.generate_content에 밈 템플릿만 추가** / 자료 필수·claims 검증·템플릿 회전이 밈에 안 맞는다.
2. **밈을 별도 포트·별도 엔진 경로로 (채택)** / 포트가 하나 늘지만 아이디어 → 중복 판정 → 대본 → 덱 흐름을 밈에 맞게 둘 수 있다.

## 결정 (제안)

- 포트 `ScenarioWriter.propose_meme_ideas(req) -> list[MemeIdea]`, `write_meme_script(req, idea) -> MemeScript`. `MemeRequest`에 관심 분야·캐릭터 이름/외형·**호출별 말투**(`workspace.meme_tone`, 전역 페르소나 말투는 덮어쓰지 않음)·최근 밈 요약·선택 훅(정보 사건 + 그 자료). Claude·OpenAI 텍스트 생성기가 함께 구현(공용 프롬프트).
- 엔진 `engine/memes.py`: 아이디어 N개 → `meme_policy.pick_idea`(중복 아닌 것) → 대본 → `build_meme_deck`(만화 첫 장 + 마무리, 그림은 비움) → 검토 대기 원고. 그림은 S15 제작이 채우고 슬롯은 `images_pending`(그 전엔 "검토 가능" 아님, 게시 관문).
- **중복**: 상황+반전 토큰(조사 제거) Jaccard ≥0.6 **이고** 대비 구조(contrast 토큰)도 겹칠 때만. 같은 캐릭터·분야의 다른 반전은 통과, 단어만 바꾼 같은 농담은 잡는다. 전부 중복이면 슬롯을 비운다(억지로 채우지 않음).
- **사실**: 숫자·날짜·가격·"출시/확정/발표"가 있는데 claims가 비면 "사실 확인 신호"(검토 사유, 오류 아님). 뉴스 훅이 있으면 claims·출처를 허용하고 기존 검증(ADR 0008)을 그대로 탄다. 창작 대사에 가짜 출처를 붙이지 않는다(훅 없으면 claims 빈 배열).
- "정보 제목에 드립만" 판정은 자동 제외 없음: 프롬프트 지시 + 검토 사유에 "정보 소재와 겹침 n%" 신호만.

## 결과

- 밈 1건 = 텍스트 호출 2번(아이디어·대본, 약 2센트). 뉴스가 없는 날도 밈 슬롯은 찬다.
- 어려워진 것: 포트 추가(합의). 그림이 없으면 밈은 미완성이라 S15 전에는 검토 화면에서 "그림 없음" 자리로 보인다.
- 테스트: 중복 사례(단어만 바꾼 같은 농담 잡힘·다른 반전 통과·같은 상황 다른 대비 통과), 사실 신호는 힌트, 정보 겹침은 신호, 엔진(밈 슬롯 생성·말투 호출별·claims 없음·공급자 없음 실패·전부 중복이면 빈 슬롯).
