# 0064. 편집 판단은 목적·자료·사진 특성을 함께 보고 정하고, 완성 카드로 다시 검토한다

- 상태: 제안
- 날짜: 2026-10-23
- 결정한 사람: 서브(제안), 사용자 피드백 2026-10-23 밤 반영, 메인 합의 전
- 관련: S18 PR(#108), ADR 0062(형식은 내용이 정한다)·0063(확인된 정보만·키치형·편집 밀도·화질)

## 배경

S18 실호출에서 겉모양이 서로 다른 실패가 나왔다.

- 표지 사진이 위쪽 낮은 띠에 갇혔다(잘림을 피하려다 너무 작아짐).
- 상품 사진이 칸을 채우다 잘렸다.
- 디테일 장인데 말하는 특징이 사진에 없었다.
- 사진과 상관없이 제목 크기·장식·여백이 같았다.

사용자는 이것을 한 장씩 고치지 말고 **소재가 바뀌어도 맞게 만드는 과정**으로 고치라고 했다. 이 앱은 상품 소개 전용이 아니고, 관심 주제의 다양한 정보 카드뉴스와 밈을 만든다. 치이카와 상품은 실패를 발견한 사례일 뿐이다.

조사해 보니 장 표현은 내용이 정했지만, 그 밖의 판단은 고정돼 있었다.
- 사진 크기·자르기·제목 크기·장식이 CSS에 박혀 있었다.
- 관찰 단계는 사진의 주인공(꼭 보여야 할 영역)을 적지 않았다.
- 원고 지침의 예시와 규칙이 상품 위주였다.
- 완성 카드를 보고 검토하는 단계가 없었다. 넘침 검사만 있었다.

## 선택지

1. **사례별 CSS 조정**(표지 띠 높이·칸 비율 숫자 바꾸기): 이번 사례만 통과하고 다른 소재에서 다시 깨진다.
2. **배치 규칙 하나로 통일**(표지는 늘 꽉 채움, 상품은 늘 contain): 한 실패를 다른 실패로 바꿀 뿐이다.
3. **판단 지점마다 내용·자료·사진 특성을 넣고, 완성 결과로 다시 검토**: 기존 흐름의 빠진 판단만 채운다.

## 결정

**3.** 기존 흐름(자료 → 관찰 → 관점·장 기획 → 사진 배치 → 렌더 → 검토)은 그대로 두고, 고정값이던 판단에 내용을 넣는다.

1. **관찰**: 사진마다 다음을 적는다(사진 종류와 상관없이).
   - 꼭 보여야 할 영역(`subject`: 인물·대상 묶음·포스터 본체·현장의 핵심)
   - 읽혀야 하는 글자 유무(`has_text`)
   - 실제 픽셀 크기
2. **기획**: 상품 중심 지침을 독자의 목적으로 바꿨다. 독자가 무엇을 알게 되고, 이해하고, 비교·판단하고, 경험하는지가 기준이다.
   - 장마다 다섯 가지를 잇는다: 핵심, 근거(사진 번호나 자료 사실), 표현, 필요한 만큼의 글, 역할.
   - 사진마다 크기와 표지 배율을 알려 준다. 표지를 크게 채울 수 있는 사진을 표지로 고르게 하고, 가로 단체 사진은 본문으로 보낸다.
   - 사진 없이도 전달되는 장에는 사진을 강요하지 않는다. 자료가 모자라면 관점 변경·합치기·생략·자료 부족 표시 중에서 고른다.
   - 쓸 사진이 있으면 표지는 사진이다. 원고가 비우면 코드가 표지를 가장 잘 채우는 사진을 고른다.
3. **배치**:
   - 표지: 주인공 영역과 해상도로 정한다. 꽉 채워도 주인공이 잘리지 않고 1.6배 안이면 꽉 채우되, 자르는 위치를 주인공 쪽으로 옮긴다. 아니면 주인공이 잘리지 않고 1.6배를 넘지 않는 만큼 크게(카드 높이 64%까지) 둔다. 아래는 진한 색 그라데이션으로 이어 제목이 사진 끝에 겹친다(빈 띠 없음).
   - 제목은 의미 단위로 줄을 나눈다(`keep-all` + `balance`).
   - 키치형 장식: 물방울·반짝이는 글이 중심인 강조 장에만 둔다. 사진 장·정보 줄 장에는 두지 않는다.
4. **완성 카드 검토**(포트 `CardReviewer`): 미리보기를 그리면 저절로 돈다.
   - 수치로 확인되는 것(넘침, 사진을 몇 배 늘렸나)은 코드가 잰다.
   - 그림을 봐야 아는 것은 그림을 보는 모델이 장마다 그 장의 목적에 맞춰 본다: 핵심 파악, 근거와 표현의 일치, 잘림·가림·왜곡·흐림, 제목 줄.
   - 문제는 원인 단계(소재·기획·배치·글)로 나눠 검토 사유에 남긴다.
   - 원인이 소재·기획이거나 표지 배치면 검토 내용을 원고에 넘겨 **한 번만** 다시 편집한다. 글 문제는 사람이 고친다. 글자를 줄여서 넘어가지 않는다.

## 결과

- 쉬워진 것: 소재가 바뀌어도 같은 판단 순서로 장을 만든다. 실패가 어느 단계에서 났는지 검토 사유에서 바로 보인다.
- 비용: 원고당 관찰 약 $0.03, 완성 카드 검토 약 $0.04, 자동 다시 편집 최대 1회(약 $0.08)가 더 든다.
- 한계:
  - 주인공 영역과 디테일 위치는 관찰 모델의 대략값이다.
  - 자료 자체가 부족하면(블로그 원본이 작음, 사진 1장) 좋은 결과를 만들 수 없다. 공식 원본·같은 소재를 새로 **검색**하는 단계는 다음 배치다.
  - 완성 카드 검토도 모델 판단이라 놓치는 것이 있다. 사람 검토는 그대로 필요하다.
- 다시 볼 조건: 자동 다시 편집이 같은 문제를 반복하면 그 원인 단계(관찰·기획 지침)를 고친다. 횟수를 늘리지 않는다.
