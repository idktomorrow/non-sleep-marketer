# 0045. 올린 이미지를 읽어 자료로 쓰기

- 상태: 제안 (배치 C16. 선웅제가 정한 것: 이미지는 "읽어서 정보로 쓰는" 용도. 카드에 사진을 넣는 쪽은 하지 않음)
- 날짜: 2026-10-17
- 결정한 사람: 선웅제(용도), 배치 C16 기본값(모델, 크기 한도, 캐시, 정보 없을 때 거절)
- 관련: [ADR 0033](0033-materials-page.md)(자료 화면), [ADR 0036](0036-code-drawn-card-styles.md)(카드는 코드로 그린 배경·직접 만든 캐릭터), [ADR 0003](0003-classifier-jev-and-claude.md)(분류기 모델)

## 배경

자료 올리기는 txt·md·csv·xlsx·pdf만 읽었다. 굿즈 소식은 이미지로 먼저 나오는 경우가 많다. 예를 들어 CGV "먼작귀 팝콘통 예약판매 OPEN, 네이버에 [CGV 스토어] 검색" 공지는 글자가 전부 그림 안에 있다. 사용자는 이런 이미지를 올리면 그 정보로 원고를 만들기를 원했다.

## 선택지

1. **이미지 속 정보를 글로 옮겨 자료로 (채택)**: Claude가 이미지를 보고 보이는 글자와 사실을 옮긴다. 그 뒤는 다른 올린 파일과 같다.
2. 올린 사진을 카드에 넣기: 굿즈 사진에는 캐릭터 저작권이 걸려 있어 ADR 0036(직접 만든 캐릭터만)과 부딪친다. 하지 않는다.
3. OCR 라이브러리(Tesseract 등): 설치가 무겁다. 꾸민 글씨(포스터 제목)를 잘 못 읽고, "구매처·디자인 3종" 같은 뜻을 정리하지 못한다.

## 결정

- 받는 형식은 png·jpg·jpeg·webp이고 5MB 이하다(Claude API 한 장 한도). 파일 앞부분으로 실제 형식을 확인해, 확장자만 바꾼 파일은 거절한다.
- 읽기(`nsm/adapters/sources/image_reader.py`)
  - 모델은 `models.classifier`(기본 `claude-haiku-5-5`)를 쓴다. 구조화 출력은 `{has_info, text}`다.
  - 지시: 보이는 글자와 사실(상품명·날짜·시간·장소·가격·수량·구매처·디자인 수)만 한국어 짧은 줄로 옮긴다. 추측하지 않고, 캐릭터 생김새나 그림체는 쓰지 않는다.
  - 글자나 정보가 없는 사진이면 `has_info=false`이고, 빈 글로 처리한다.
  - 비용은 `llm` 종류로 기록한다(`CostKind`는 동결 계약). 실제 한 장에 약 $0.0001~0.0002가 든다.
- 한 번만 읽기: 결과를 `<NSM_HOME>/upload-text/<파일 키>.txt`에 둔다. 파일 키는 경로·크기·수정 시각이다. 대시보드에서 올릴 때 읽고, 자료 모으기는 캐시를 쓴다. 파일을 고치면 다시 읽는다. 실패(거절·오류)는 캐시하지 않는다.
- 올릴 때(대시보드 "오늘"·"자료")
  - 바로 읽어 보고, 옮긴 글 앞부분(200자)을 안내에 보여 준다. 무엇이 자료가 될지 그 자리에서 확인할 수 있다.
  - 정보가 없거나 Claude 키가 없거나, 형식·크기가 맞지 않으면 저장하지 않고 이유를 보여 준다.
  - 읽는 동안 몇 초 걸리므로 스레드에서 돈다(대시보드가 멈추지 않게).
- 폴더에 직접 넣은 이미지: 자료 모으기 때 읽는다. Claude 키가 없으면 조용히 건너뛴다.
- 비용 상한은 따로 확인하지 않는다. 사람이 한 장씩 올리는 일이고 한 장 값이 매우 작다. 폴더 자료는 한 번 모을 때 소스 상한(기본 30건) 안에서만 읽는다.
- 옮긴 글은 다른 자료처럼 관련성 판정, 원문 출처 표시, 출처 검증을 거친다. 카드에는 이미지를 넣지 않는다.

## 결과

- 공지 캡처·포스터·가격표를 올리면 그 정보로 원고를 만들 수 있다.
- 실제 확인: CGV 팝콘통 공지와 비슷한 포스터를 읽혔다. 결과는 "CGV 먼작귀 팝콘통 예약판매 오픈 / 구매처: 네이버에서 [CGV 스토어] 검색"이었고 $0.00016이 들었다. 글자 없는 사진은 빈 글이었다($0.00009).
- 어려워진 것
  - 옮긴 글은 Claude가 읽은 것이라 틀릴 수 있다(작은 글씨, 날짜). 그래서 올릴 때 미리보기로 바로 확인하게 했다. 원고는 평소처럼 출처 검증을 거친다.
  - 출처는 "올린 파일"(파일 이름)로 남는다. 원래 게시처(CGV 공지 주소)는 알 수 없다.
- 다시 볼 조건
  - 옮긴 글을 사람이 고치고 싶다는 요청이 오면 "옮긴 글 고치기"를 검토한다.
  - 5MB를 넘는 사진이 자주 오면 줄여서 보내기(Pillow)를 검토한다.
