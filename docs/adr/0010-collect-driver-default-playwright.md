# 0010. 배치 B 검증 전까지 브라우저 드라이버 기본값을 Playwright로 둔다

- 상태: 대체됨([0017](0017-aside-default-driver-after-day1.md)) (배치 B 결과) · 날짜: 2026-10-11 · 관련: [ADR 0002](0002-aside-default-driver-split.md), 이슈 #3

## 배경

ADR 0002는 Aside를 기본 드라이버로 정했지만, Aside CLI가 사람 승인 없이 동작하는지와 정확한 명령 형식은 배치 B(1일차 검증)에서야 확인된다. 그 전에 Aside 드라이버를 추측으로 구현하면 틀릴 가능성이 높다. 반면 배치 D1의 수집 소스(네이버, 커뮤니티)는 드라이버가 있어야 실제로 돈다.

## 결정

설정 `browser_driver`의 기본값을 `playwright`로 두고, Aside 드라이버는 배치 B 검증 결과를 보고 배치 G에서 구현한다. 검증에서 Aside 무인 동작이 확인되면 새 ADR로 기본값을 `aside`로 되돌린다.

## 결과

- 수집은 Playwright 전용 프로필(수집 전용 계정)로 바로 동작한다.
- 어댑터와 드라이버가 분리돼 있어(ADR 0002) 기본값 전환은 설정 한 줄이다.
