# 0022. 관련 자료로 판정된 글만 원문 본문을 가져온다

- 상태: 채택 (배치 Q1)·채택 2026-10-13(선웅제) · 날짜: 2026-10-13 · 관련: [0001](0001-local-browser-automation.md)(위험 완화 수정), 이슈 #42

## 배경

[0001](0001-local-browser-automation.md)의 위험 완화로 웹 수집은 검색 결과 화면의 링크와 요약문(약 300자)만 읽었다. 2026-10-12 드라이런(실제 키)에서 이 때문에 글이 얇았다.

- 원문 제목은 "기준 5가지"였지만, 요약문에 보인 3가지만 다뤘다.
- 같은 문장이 카드마다 되풀이됐다.

## 선택지

1. **요약문만 유지**: 사이트 부담과 복제 위험이 가장 작다 / 글 품질이 낮고, 다루지 못한 내용이 생긴다
2. **모든 수집 글의 본문**: 품질은 좋다 / 하루 수십 번 원문을 열어 사이트 부담과 차단 위험이 커지고, 쓰지 않을 글까지 읽는다
3. **관련 자료로 판정된 글만, 상한을 두고 본문**

## 결정

3번.

- **대상:** 관련성 판정을 통과한 글만. 한 번 수집할 때 최대 6개이고, 요청 사이에는 기존 무작위 지연을 둔다.
- **상한:** 본문은 정리(화면 낭독기 문구, 메뉴 줄, 보이지 않는 글자 제거)한 뒤 3,000자까지 쓴다. 생성 프롬프트도 자료당 3,000자까지만 쓴다.
- **실패 처리:** 본문을 못 찾거나 200자보다 짧으면 요약문을 그대로 쓴다. 같은 글은 다시 시도하지 않는다(`classifications`에 `kind='body'`로 기록).
- **네이버 블로그:** PC 주소는 본문이 iframe 안에 있어 모바일 주소(`m.blog.naver.com`)로 연다.
- **용도:** 본문은 생성 재료로만 쓴다. 생성 규칙(원문 문장을 20자 넘게 그대로 옮기지 않음, 사실마다 출처)은 그대로이고, 게시물에는 출처 줄이 붙는다.

## 결과

- 2026-10-13 실측: 그라인더 글 본문 2,564자를 가져와 "기준 5가지"를 모두 다룬 원고가 나왔다(devlog 배치 Q1).
- 수집 시간이 글 하나당 수 초 늘어난다(관련 글만이라 하루 몇 개 수준).
- 사이트 약관상 자동화 위험은 0001에서 사용자가 감수하기로 한 범위 안이다. 원문을 여는 횟수는 관련 글 수로 제한된다.
