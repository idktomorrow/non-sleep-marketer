# 0024. 카드 편집 화면: 슬라이드 문구·배경·미리보기만, 스타일 선택은 S8 뒤로

- 상태: 제안 (배치 M16) · 날짜: 2026-10-13 · 관련: 이슈 #35, #34(S8), [0019](0019-label-wording-and-placement.md), [0023](0023-code-checked-content-rules.md)

## 배경

M16은 검토 상세 화면에서 마케터가 카드를 직접 다듬게 하는 작업이다. 범위는 슬라이드별 문구, 배경 이미지 올리기·바꾸기, 스타일 선택, "미리보기 렌더", 저장 때 기존 PNG 삭제였다. 정해야 할 것이 네 가지였다.

- 스타일 선택: 기준이 되는 `brand.card_style`(S8 #34)이 아직 없다.
- "AI 생성 이미지" 표기: 이 표기는 덱 전체에 하나뿐이다(동결 계약). 사람이 사진을 올리면 이 표기를 어떻게 할지 정해야 했다.
- 미리보기: 게시용 렌더 캐시(`media/cards`)와 섞이지 않게 해야 했다.
- 출처 편집: 출처를 고칠 수 있게 할지 정해야 했다.

## 결정

- **스타일 선택은 S8 뒤로 미룬다.** 스타일이 하나뿐이라 고를 것이 없다. S8이 `brand.card_style`과 스타일 템플릿을 넣으면, 같은 화면에 선택 칸을 한 줄 더한다. 콘텐츠별 스타일(덱 `style` 필드)은 S8 2차의 계약 변경과 함께 한다.
- **문구:** 표지(제목·부제), 본문(소제목·본문·목록), 목록(소제목·목록), 비교(소제목·양쪽 제목·항목), 마무리(마무리 문구)를 고친다. 목록은 한 줄에 하나씩 쓰고 앞 번호·기호는 뗀다(0023). 덱 계약에 맞지 않으면(예: 목록이 0개) 400으로 돌려주고 저장하지 않는다. 폼에 없는 칸은 그대로 둔다(예전 폼과 호환).
- **출처는 고치지 않는다.** 출처는 사실 주장의 근거라 사람이 바꾸면 검증 고리(claim → 자료)가 끊긴다.
- **배경 업로드:**
  - PNG·JPEG·WebP만 받고, 형식은 파일 앞 바이트로 판정한다(이름·Content-Type은 믿지 않음).
  - 10MB 이하만 받는다.
  - 저장 이름은 우리가 만든다(`media/uploads/backgrounds/<id>/slide-NN-<무작위>.ext`).
- **"AI 생성 이미지" 표기:** 이미지 생성기가 만든 배경(`media/bg-*.png`)이 하나라도 남아 있으면 켜고, 사람이 올린 사진만 남으면 끈다. 표기가 덱 단위라 AI 배경과 사진이 섞이면 사진 장에도 캡션이 붙는다. 표기가 빠지는 쪽보다 안전하다.
- **미리보기:** `media/previews/<id>`에 따로 그린다. 그리는 일은 잡 스레드(`submit`)에서 해서, 게시 잡의 렌더와 겹쳐 넘침 결과가 섞이지 않게 한다. 넘친 장이 있으면 화면에 알린다. 저장하거나 배경을 바꾸면 게시용 카드와 미리보기를 함께 지운다.
- **자유 배치 편집기**(끌어서 놓기)는 범위 밖이다.

## 결과

- 마케터가 글 넘침을 게시 전에 확인하고 고칠 수 있다. 게시 때 넘치면 다시 검토 대기열로 돌아온다.
- 배경 업로드는 검토 대기 중인 콘텐츠에만 된다(승인 뒤에는 잠김).
- 다시 볼 조건: S8이 들어오면 스타일 선택 칸을 추가한다. 장별 AI 표기가 필요해지면 덱 계약 변경으로 슬라이드 단위 플래그를 검토한다.
