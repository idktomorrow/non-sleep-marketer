# 0001. 사용자별 로컬 설치 + 브라우저 자동화로 운영한다 (공식 API 미사용)

- 상태: 채택 · 날짜: 2026-10-11 · 결정: 선웅제 · 관련: [planning-decisions](../planning-decisions.md) Round 2~3 (Q17~Q19, Q22)

## 배경

각 사용자가 자기 브랜드·계정·API 키로 쓰는 도구다. Meta 공식 API(Instagram Graph, Threads)를 쓰려면 개발자 앱 등록·심사가 필요하고, 개발 모드는 테스터 최대 50명이다. 네이버는 블로그 글쓰기 공식 API가 사실상 없고 검색 API는 2026-09 약관으로 AI 요약·저장이 금지됐다.

## 선택지

1. **공식 API + 서버(SaaS)**: 안정적, 약관 안전 / 앱 심사·호스팅·멀티테넌시 비용, 네이버 블로그 불가
2. **사용자 PC에서 로그인된 브라우저를 자동화**: 세 플랫폼 모두 가능, 서버 없음, 데이터가 PC 밖으로 안 나감 / 약관 위반 소지(계정 제재 위험), UI 변경에 취약

## 결정

2번. 세 플랫폼을 2주 안에 다루는 유일한 경로이고, 사용자가 제재 위험을 고지받고 감수하기로 했다.

## 결과

- 위험 완화를 기능으로 넣어야 한다: 위험 고지 동의, 낮은 빈도와 지터, 일일 쿼터, 수집 전용 계정, 원문 복사 금지.
- UI 변경에 깨지므로 어댑터 계약 테스트(실계정, 수동 실행)가 필수다.
- 공식 API 재검토 조건: 계정 제재가 실제로 발생하거나 SaaS로 전환할 때.
