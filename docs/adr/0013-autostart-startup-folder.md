# 0013. 자동 실행은 작업 스케줄러 대신 사용자 시작프로그램 폴더로 등록한다

- 상태: 채택(2026-10-13, 배치 B 반영 PR에서 선웅제 확정) · 날짜: 2026-10-11 · 관련: 이슈 #13, PRD 사용자 스토리 58

## 배경

계약 초안은 `schtasks /SC ONLOGON`(Windows 작업 스케줄러)으로 로그온 시 실행을 등록하기로 했다. 그런데 로그온 트리거 작업은 관리자 권한을 요구하는 경우가 많다. 일반 사용자가 "관리자 권한으로 실행"을 따로 해야 하면 설치가 막힌다.

## 선택지

1. **작업 스케줄러**: 재시도·지연 시작 같은 옵션이 많음 / 관리자 권한 필요할 수 있음
2. **사용자 시작프로그램 폴더(`shell:startup`)에 .cmd 파일**: 권한 불필요, 지우면 해제 / 옵션이 적음
3. Windows 서비스: 로그인 전에도 실행 / 브라우저 로그인 세션·알림과 맞지 않음

## 결정

2번. 브라우저 프로필·데스크톱 알림이 사용자 세션에 묶여 있어서 "로그온 후 실행"이면 충분하다.

## 결과

- `nsm install-autostart`가 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\non-sleep-marketer.cmd`를 만들고, 최소화된 창에서 `uv run nsm run`을 실행한다. 출력은 `<NSM_HOME>\logs\nsm-run.log`.
- `.cmd`는 cmd.exe가 시스템 ANSI 코드 페이지로 읽으므로 그 인코딩으로 저장한다.
- 프로세스가 죽었을 때 자동 재시작은 없다. 필요해지면 작업 스케줄러(1번)를 다시 검토한다.
