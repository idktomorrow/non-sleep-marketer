# 0070. 문서 질문 화면은 질문하러 오는 화면으로 두고, 검색 측정은 맨 아래 개발용으로 접으며, 근거 접힌 줄은 짧은 제목만 보인다

- 상태: 제안
- 날짜: 2026-11-13
- 결정한 사람: 선웅제(배치 R6 요청), 세부는 Claude
- 관련: [ADR 0058](0058-rag-doc-chat.md)(문서 질문 화면), [ADR 0065](0065-collected-and-posts-sources.md)(출처 고르기), [ADR 0068](0068-post-metrics-at-answer-time.md)(성과 요약), devlog [2026-11-13-batch-R6](../devlog/2026-11-13-batch-R6.md)

## 배경

- R3~R5를 거치며 화면에 기능이 하나씩 붙었다. 그래서 질문하러 온 사람이 보는 순서가 아니라 기능이 생긴 순서대로 쌓였다. 이전 화면(`docs/samples/ui/before/24-ask-*.png`, 예시 기록을 넣은 임시 서버 화면) 기준으로 셋이 문제였다.
  - 맨 위 안내가 두 문단이다(출처 목록·기준값·조각 수).
  - 검색 측정 표가 답과 최근 질문 사이에 있다. 이 표는 개발자가 검색 품질을 잴 때만 본다.
  - 근거 접힌 줄에 "devlog/… > 문서 제목 > 절 제목" 경로 전체가 나와 휴대폰에서 네댓 줄이 된다.
- 최근 질문은 6열 표였다. 400px에서는 답 칸이 좁아 세로로 길어지고, 표 안에서 가로로 스크롤해야 했다.

## 선택지

1. **측정을 다른 탭(예: 설정)으로 옮기기**: 질문 화면이 가장 깔끔해진다 / 라우트·리다이렉트(`/ask?eval=…#eval`)와 테스트를 옮겨야 한다. 이번 배치 범위(화면만)를 넘는다.
2. **측정을 맨 아래 `<details>`로 접기**: 라우트·주소는 그대로이고, `#eval`이나 결과 안내가 있으면 펼쳐 연다 / 같은 페이지에 남는다.
3. **근거 제목을 템플릿에서 자르기(앞 N자)**: 간단하다 / 한국어 제목이 중간에서 잘리고, 문서는 파일명이 앞이라 정작 절 제목이 안 보인다.
4. **근거 제목을 경로 규칙으로 고르는 순수 함수(`ask_format.source_title`)**: 출처마다 무엇이 "제목"인지 테스트로 고정한다. 길이는 CSS 말줄임으로 처리하고 글자는 자르지 않는다.

## 결정

2와 4를 고른다. 가장 중요한 이유는 서버 동작(라우트·주소·DB)을 하나도 바꾸지 않고 화면만 다시 짤 수 있다는 점이다.

- 순서는 질문 칸 → 답 → 최근 질문 → 검색 측정(개발용, 기본 접힘)이다. 측정 결과 안내(`eval_notice`)가 있으면 서버가 `open`을 붙이고, 주소가 `#eval`이면 `ask.js`가 펼친다.
- 근거 제목 규칙(`source_title(heading, kind) -> (짧은 제목, 보조 제목)`)은 제목 경로를 " > "로 나눠 정한다.

  | 출처 | 짧은 제목 | 보조 제목 |
  | --- | --- | --- |
  | 문서(kind 없음 포함) | 마지막 절 제목 | 문서 제목(첫 제목) |
  | 수집 자료 | 기사 제목 | 없음 |
  | 우리 글 | 글 제목 | 절(카드 문구·댓글) |

  - 문서에 제목이 하나뿐이면 그 제목을 짧은 제목으로 쓴다. 제목이 없으면 파일명을 쓴다.
  - 성과 요약은 그 제목("성과 요약(…)")을 쓴다.
  - 파일명을 포함한 전체 경로는 펼쳤을 때 첫 줄에 보인다.
- 최근 질문은 표 대신 카드 목록이다. 카드에는 질문 한 줄, 답 미리보기 두 줄(`line-clamp`), 날짜·근거 배지·비용·지우기가 들어간다.
  - "요약" 배지에는 `ask.summary_ids`가 쓰인다. 최근 20개 id에 대해 근거의 `path`가 `posts/_summary`인지 보는 읽기 전용 질의다. 근거 본문은 파이썬으로 가져오지 않는다(R3c 리뷰 원칙).
- 출처 고르기는 `<select>` 대신 라디오 칩 넷(전체·문서·수집·우리 글)이다. `name="source"`와 값은 R4 그대로다.
- 예시 질문 칩 넷은 `type="button"`이다. 누르면 질문 칸에 넣기만 하고 묻지 않는다. 측정 질문 원문은 쓰지 않는다(쓰면 측정이 쉬워진다. 테스트가 막는다).
- 답 카드의 모델 이름은 `title` 속성으로만 둔다. 비용·시간만 작은 회색으로 보인다.

## 결과

- 쉬워진 것
  - 처음 온 사람이 예시를 눌러 바로 물을 수 있다.
  - 400px에서 근거를 펼쳐도 가로 스크롤이 없다(`scrollWidth` 400). 측정 표만 `table-wrap` 안에서 스크롤한다.
- 어려워진 것
  - 측정 표를 보려면 한 번 더 눌러야 한다(측정 직후에는 펼쳐져 있다).
  - 질문당 비용 어림(Gemini 1건·Claude 약 N원)은 "자세히" 안이라 묻기 전에 바로 보이지 않는다. 실제 비용은 답 카드와 최근 질문 카드에 보인다.
- 다시 볼 조건
  - 측정을 자주 보게 되거나 측정 종류가 늘면 선택지 1(별도 탭)로 옮긴다.
  - 제목 경로 형식(chunker `" > "`, `Document.label`)이 바뀌면 `source_title`을 함께 고친다.
