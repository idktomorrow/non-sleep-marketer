# 0007. 가상인물·AI·광고 표기를 텍스트와 이미지 양쪽에 강제하고, 후기형 콘텐츠는 만들지 않는다

- 상태: 채택 (문구는 배치 B에서 원문 대조 후 확정) · 날짜: 2026-10-11 · 결정: 선웅제 · 관련: [mvp-review](../mvp-review.md) #2·#3, Round 4 Q26, [contracts 5절](../contracts.md)

## 배경

- 공정위 추천·보증 심사지침 개정(2026-06-01 시행, 계도기간 없음): AI로 만든 가상인물을 추천·보증인에 포함. 문자 매체는 제목·첫 부분에 표시(예시 "AI를 기반으로 생성된 가상인물이 포함된 게시물입니다", "가상인물 포함"), 사진·영상은 인물 인근에 "가상인물". 표시를 해도 실제 사용 경험에 기반한 추천처럼 표현하면 부당 광고.
- AI 기본법 제31조(2026-01-22 시행): 생성형 AI 결과물 표시 의무, 과태료는 1년 이상 유예.
- 원래 템플릿 3종 중 "후기형"은 페르소나가 직접 후기를 쓰는 구조였다.

## 선택지 (후기형)

1. 고객 후기 인용형으로 변경
2. **후기형 제거, 비교형으로 대체**
3. 유지하고 위험 고지만

## 결정

표기는 텍스트 첫 줄 + 카드 배지 + 광고 표기의 3층으로 강제(끌 수 없음). 후기형은 2번.

## 결과

- 템플릿에 `data-label` 표기 슬롯이 필수 계약이 되고 렌더 테스트가 검사한다.
- 1인칭 체험 표현이 기본 금칙 패턴이다. 실제 고객 후기는 업로드 자료로 출처와 함께 인용만 허용.
- 문구는 `nsm/domain/labels.py` 상수 한 곳에만 둔다.
