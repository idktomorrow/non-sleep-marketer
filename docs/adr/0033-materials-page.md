# 0033. 자료 화면: 파일 올리기와 자료 판정 보기

- 상태: 채택 (선웅제 요청, 2026-10-13) · 날짜: 2026-10-13 · 관련: [0022](0022-fetch-article-body-for-relevant-items.md), [0032](0032-fresh-sources-and-no-rumors.md)

## 배경

브랜드 자료는 `%USERPROFILE%\.nsm\uploads` 폴더에 직접 넣어야 했다. 넣은 파일이 제대로 읽혔는지, 관련 자료로 판정됐는지, 원고에 쓰였는지 볼 화면도 없었다. 대시보드에서는 "쓸 수 있는 자료" 숫자만 보였다.

## 결정

대시보드에 **자료** 탭(`/materials`)을 둔다.

- **파일 올리기**: txt·md·csv·xlsx·pdf, 20MB 이하. 올리는 순간 글을 읽어 보고 읽은 글자 수를 알려 준다. 읽지 못하는 파일(형식 밖, 빈 파일, 깨진 PDF, 스캔 이미지 PDF)은 저장하지 않고 이유를 보여 준다. 파일 이름은 경로와 금지 문자를 빼고 저장한다. 같은 이름이 있으면 덮어쓰지 않고 번호를 붙인다. 폴더에 직접 넣는 방법도 그대로 된다.
- **올린 파일 목록**: 파일마다 자료 상태를 보여 준다. 아직 안 읽음, 판정(관련 있음·없음·후기 제외·판정 실패), 고친 뒤 아직 안 읽음, 쓰인 원고. 파일 지우기는 uploads 폴더 안의 파일만 된다. 이미 모은 자료는 남는다.
- **모은 자료 목록**: 최근 150개를 보여 준다. 전체·네이버·올린 파일·구글 트렌드로 거르고, 판정(점수)·주제·쓰인 원고를 함께 본다.
- 올린 파일은 바로 자료가 되지 않는다. 다음 "자료 모으기" 때 다른 자료와 같은 판정을 거친다. 화면에 "자료 모으기 지금 실행" 버튼을 둔다.

## 결과

- 브랜드 자료를 넣고 확인하는 일을 대시보드 안에서 끝낼 수 있다.
- 올린 파일도 관련성 판정을 거친다. 관심 주제와 동떨어진 자료는 원고에 쓰이지 않는다.
