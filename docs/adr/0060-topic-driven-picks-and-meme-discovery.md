# 0060. 관심 주제 하나가 정보·밈 추천의 소재를 정하고, 밈 사례는 근거와 분류를 남기며, 캐릭터는 사람이 고른다

- 상태: 제안
- 날짜: 2026-10-21
- 결정한 사람: 서브(제안), 메인 합의 전
- 관련: S16 PR, ADR 0051(추천)·0056(밈 경로)·0058(출연진), `docs/devlog/2026-10-21-batch-S16.md`

## 배경

OpenAI 실호출 검증(S15)에서 밈이 "루나의 핸드드립" 이야기로, 주인공은 견본 흰 캐릭터로 나왔다. 원인은 세 가지였다.

- `meme_request`가 페르소나 이름·인물상을 주인공으로, 페르소나 관심 주제 전체를 소재로 넘겼다. 테스트 픽스처 페르소나가 커피 바리스타 "루나"다.
- 그림 제작이 고른 캐릭터가 없을 때 저장소 견본 스티커를 참조로 썼다(검증 스크립트).
- 프롬프트 말투 예시가 커피 어휘였다("물 온도가 맛을 바꿔요").

또 설정 화면에는 S11의 "관심 분야 묶음" 버튼이 '관심 주제' 입력과 같은 일을 따로 하고 있었다.

## 선택지

1. **분야 프리셋을 늘리고 분야별 프롬프트를 둔다**: 분야마다 손이 많이 가고, 입력이 둘이 된다.
2. **관심 주제 입력 하나를 수집 → 후보 → 대본 → 그림 계획까지 그대로 잇는다**: 입력이 하나라 헷갈리지 않는다. 분야 지식은 프롬프트의 일반 가이드와 실제 자료에서 온다.

## 결정

2를 고른다. 사용자가 적은 관심 주제가 무엇을 다룰지 정하고, 정보 N + 밈 M은 구성일 뿐이다.

- **주제 순환**: 종류별(정보·밈)로 최근 추천에서 가장 오래 안 다룬 주제부터 쓴다(`domain/topics.topic_order`). 슬롯 번호로 돌리지 않는다. 한 게시물에 주제 하나.
- **밈 사례 탐색**(`adapters/sources/meme_discovery.py`): 네이버 블로그·카페 공개 검색과 설정의 커뮤니티 URL에서 "<주제> 밈/짤"을 찾는다. X는 로그인·API 없이 볼 수 없어 수집하지 않고, 결과에 보인 x.com 링크만 발견 경로로 남긴다. 반응 수치는 못 가져오면 null(미확인)이다.
- **분류**(`domain/meme_discovery.classify`): A 최근 확산 확인(서로 다른 작성자 3명 이상, 최근 7일 안), B 지속 형식(30일 넘게 이어짐), C 근거 부족 발견, D 창작(참고 사례 없음). "급상승"은 시간차 관측이 없으므로 쓰지 않는다.
- **발견 ≠ 제작**: 사례는 상황·감정·반전 구조만 참고하고 대본은 새로 쓴다. 실존 인물이 하지 않은 행동·발언을 사실처럼 쓰지 않는다.
- **중복**: 모델에 최근 밈 목록을 주고 "의미상 같은 농담"이면 `same_as_recent`로 표시하게 한다. 토큰 겹침은 보조 신호로 남긴다.
- **캐릭터**: 사용자가 고른 주인공(작업 공간 기본 또는 원고별)만 쓴다. 없으면 대본은 만들고 주인공 후보를 제안만 한 뒤 그림 전에 "캐릭터·참조 필요"로 멈춘다. 페르소나 이름·브랜드 그림으로 주인공을 만들지 않는다.
- **정보·이슈**: 이슈는 공식 소식·화제이지 논란·루머가 아니다. 날짜는 종류(예약·출시·배송·행사)와 지역(일본·국내)을 나눠 적고, 미상·상충은 "확인 필요"로 둔다.
- **충돌 경고**: 계정 설명(업종·인물상)과 관심 주제가 어긋나면 추천함 위에 경고만 띄운다. 덮어쓰지 않는다.
- **OpenAI 분류기**: OpenAI 키만 있을 때도 관련성·주제를 모델이 판정한다(Gemini·Claude 뒤, 낱말 규칙 앞). 낱말 규칙은 "한국 아이돌"을 글에서 글자 그대로 찾지 못해 실검증에서 관련 자료가 0건이었다.
- **같은 사건 확인**: 제목 낱말 겹침이 낮아도 모델에 "오늘 만든 소식과 같은 사건인가"를 묻고 같으면 건너뛴다(낱말 규칙 분류기뿐이면 묻지 않음).
- **결과 날짜**: 네이버 새 결과 화면은 날짜가 링크 블록 위 칸에 있어, 링크 요약문에 그 항목의 날짜 표기를 붙인다(목록 경계를 넘지 않음).
- "관심 분야 묶음" 버튼과 `/settings/interest-preset`은 없앤다. 별칭·제외어 입력과 작업 공간(프리셋)은 그대로다.

## 결과

- 쉬워진 것: 주제를 적기만 하면 같은 주제가 수집·후보·대본·그림 계획까지 이어지고, 추천 카드에서 근거와 확인 시각을 본다.
- 어려워진 것: 캐릭터를 고르기 전에는 밈 그림이 나오지 않는다. 의도한 제약이다.
- 다시 볼 조건: X 공식 API를 쓰게 되면 A 분류에 반응 수치를 넣는다. 같은 사례를 여러 날 관측하게 되면 "확산 중" 판정을 시간차로 바꾼다. 같은 행사의 다른 연사 기사를 같은 사건으로 볼지 기준을 다듬는다.
