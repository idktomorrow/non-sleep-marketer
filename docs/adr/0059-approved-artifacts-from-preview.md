# 0059. 승인 = 사용자가 본 미리보기 판을 굳히기, 게시는 굳힌 산출물만

- 상태: 제안 (배치 S15, 서브 제안 PR)
- 날짜: 2026-10-21
- 결정한 사람: 서브(제안 초안). 2026-10-21 사용자 리뷰 반영(승인 시 재렌더 결과를 바로 승인하지 않음, 임시 경로→해시→이름 바꾸기, 유실 시 재렌더 금지, 기존 원고 마이그레이션)
- 관련: [0058](0058-cast-and-persistent-image-jobs.md), [0024](0024-card-editor-scope.md)(카드 편집), ADR 0036(스타일은 렌더 시점 설정)

## 배경

카드 스타일·캐릭터·템플릿은 렌더할 때 전역 설정에서 읽는다. 그래서 승인 뒤 설정을 바꾸면 이미 승인한 원고의 게시 카드가 몰래 바뀌었고, 승인 때 새로 그린 결과는 사람이 본 미리보기와 다를 수 있었다.

## 선택지

1. **승인 때 스타일·해시만 저장하고 게시 때 다시 그림** / 폰트·템플릿·그림 파일이 바뀌면 복원할 수 없다.
2. **승인 때 새로 렌더해 굳힘** / 사람이 본 것과 다를 수 있다.
3. **미리보기 판(manifest)을 남기고, 승인은 그 판을 그대로 굳힘 (채택)**.

## 결정 (제안)

- 미리보기를 그리면 `preview_manifests`에 원고 판 번호(`contents.revision`, 고칠 때마다 +1) + 지문(표기 넣은 덱 JSON, 렌더러 판 = 템플릿·스타일·캐릭터, 덱이 가리키는 그림 파일 내용) + PNG 묶음 해시를 남긴다.
- 사람 승인(검토 승인·추천 "게시")은 **최신 미리보기가 지금 상태와 같을 때만**: 판 번호·지문·파일 해시가 같고 넘침이 없어야 한다. 다르면 승인하지 않고 미리보기를 새로 그려 상세 화면에서 보여 준다("확인 후 다시 승인").
- 굳히기: 미리보기 PNG를 `approved/<id>/.tmp-…`에 복사 → 해시 검증 → 이름 바꾸기(`rev<N>-<판>`) + 캡션(`captions.json`) → `approved_artifacts`. 승인 전이가 실패하면 기록을 지운다.
- 게시: 산출물이 있으면 그 PNG·캡션만 쓴다. 산출물 판 ≠ 원고 판이거나 파일이 사라졌으면 **다시 그리지 않고** 게시를 포기·검토로 돌리고 알린다. 정책 자동 승인(사람이 본 미리보기 없음)은 게시 때 한 번 그려 그 판을 굳혀 플랫폼·재시도가 같은 PNG를 쓴다.
- 마이그레이션(시작 시 한 번): 산출물 없이 사람이 승인한 원고는 게시용 렌더(`media/cards/<id>`)가 있으면 채택(`legacy`), 없으면 검토로 돌리고 알림. 정책 승인은 그대로.
- 렌더러 포트는 바꾸지 않는다(`render(deck, out_dir)` 그대로, 판은 `renderer.version`).

## 결과

- 승인 뒤 전역 디자인 설정을 바꿔도 승인한 카드는 그대로 나간다. 렌더러가 없는 환경(테스트·초기)은 예전처럼 승인된다.
- 어려워진 것: 첫 승인 클릭이 미리보기를 요구할 수 있다(한 번 더 누른다). 산출물 폴더가 쌓인다(정리는 후속).
- 테스트: 미리보기 없이 승인 → 미리보기 후 재승인, 설정 바뀜 → 재미리보기, 굳힌 PNG로 게시(재렌더 없음), 판 바뀜·파일 유실 → 게시 중단, 마이그레이션 채택/되돌림.
