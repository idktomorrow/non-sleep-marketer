# 0002. Aside를 기본 브라우저 드라이버로, Playwright를 대안으로 두고 드라이버를 어댑터에서 분리한다

- 상태: 채택 (배치 B 검증 결과로 기본값이 바뀔 수 있음) · 날짜: 2026-10-11 · 결정: 선웅제 · 관련: [mvp-review](../mvp-review.md) #9, 이슈 #3, #14

## 배경

Aside는 크로미움 기반 AI 브라우저로 CLI·MCP를 제공하고 2026-09-14 윈도우판이 나왔다. 그러나 YC 소개에 "결제·게시·메시지 같은 민감한 행동은 사용자 승인을 기다린다"고 명시돼 있다. 권한 규칙(Allow/Ask/Deny)으로 승인을 생략할 수 있는지는 문서로 확인되지 않았다. 무료는 월 500크레딧.

## 선택지

1. **Aside만**: 로그인·화면 이해를 Aside가 처리 / 무인 동작 불확실, 크레딧 소모
2. **Playwright 저장 프로필만**: 무인 동작 확실, 무료 / 선택자 유지보수를 직접 해야 함
3. **Aside 기본 + Playwright 대안, 드라이버를 얇은 인터페이스로 분리**

## 결정

3번. 사용자가 Aside를 원했고, 분리해 두면 1일차 검증이 실패해도 교체 비용이 드라이버 파일 하나로 한정된다.

## 결과

- 플랫폼 어댑터(무엇을 할지)와 드라이버(어떻게 클릭할지)가 나뉜다. 어댑터는 드라이버를 주입받는다.
- 배치 B에서 무인 게시가 안 되면 새 ADR로 기본값을 Playwright로 바꾼다.
- 크레딧이 부족해도 Playwright로 전환한다.
