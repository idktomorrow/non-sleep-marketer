# 0036. 카드 스타일 clean·photo·illust는 코드로 그린 배경만 쓰고, AI 배경 이미지는 기본으로 끈다

- 상태: 채택 (2026-10-15, PR #69 리뷰에서 선웅제가 photo·illust 디자인과 캐릭터, 썸네일 가독성, 대기 원고 다시 그리기 동작을 승인)
- 날짜: 2026-10-14
- 결정한 사람: 선웅제(배치 지시: 유료 이미지 생성 제외), 배치 S8 기본값
- 관련: 이슈 #34, [ADR 0034](0034-main-takes-s-beta-gamma-s8.md), [ADR 0035](0035-cover-readable-at-threads-thumbnail.md), [ADR 0024](0024-card-editor-scope.md), [레퍼런스](../samples/references/README.md), 샘플 [docs/samples/styles/](../samples/styles/)

## 배경

S8은 카드 스타일을 지금의 하나(브랜드 색 면 + 흰 카드)에서 사진형·일러스트형까지 고를 수 있게 하는 작업이다. 이슈 설계 메모는 배경 사진·일러스트를 OpenAI Images로 생성하는 안이었다.

- 이미지 생성은 장마다 요금이 든다. 사용자는 이번 범위에서 유료 이미지 생성을 빼기로 했다(배치 지시).
- 지금 설정 기본값 `image_generation: auto`는 OpenAI 키만 있으면 이미지를 만든다. 키를 넣는 순간 비용이 생긴다.
- 글자를 이미지에 구우면 한글이 깨질 수 있고, 표기 슬롯(가상인물·광고) 검사를 할 수 없다.
- S-γ에서 표지 글자 최소 크기를 정했다(ADR 0035). 새 스타일도 지켜야 한다.

## 선택지

1. **AI 이미지로 배경·캐릭터 생성**: 사진·그림 느낌이 가장 진하다 / 장마다 비용, 결과가 매번 다르고 캐릭터가 일정하지 않다.
2. **무료 스톡 사진 사용**: 비용 없음 / 주제와 맞는 사진 고르기를 자동화하기 어렵고, 라이선스 확인이 필요하다.
3. **코드로 그린 배경(CSS 그라디언트·도형·SVG) + 자체 SVG 캐릭터**: 비용 없음, 결과가 늘 같고 브랜드 색을 따른다, 테스트할 수 있다 / 실제 사진만큼 풍부하지 않다.

## 결정

3번. 세 스타일 모두 코드로 그린 배경만 쓴다. 가장 큰 이유는 비용이 0이면서 결과가 결정적이라 테스트로 지킬 수 있다는 점이다.

- **clean**: 지금 스타일 그대로. 기존 샘플 PNG와 바이트까지 같다.
- **photo**: 주 색을 아주 어둡게 깐 꽉 찬 배경, 고리·사선 띠·점 무늬, 아래쪽 어둡게, 줄마다 형광펜 상자를 씌운 제목, 흰 말풍선(부제·본문 문단·마무리 문구).
  - 배경 사진이 있는 장(직접 올린 사진, AI 배경)은 사진을 쓴다. `base.css`의 `.slide.has-bg`가 뼈대다.
- **illust**: 파스텔 + 점 무늬 바탕, 모서리 얼룩, 표지·마무리의 언덕과 페르소나 캐릭터, 본문 장 위 띠의 작은 캐릭터, 흰 스티커 번호 카드, 테두리 말풍선.
  - 캐릭터는 저작권 캐릭터가 아니다. 둥근 몸 + 새싹 도형으로 새로 그렸고, 몸 색은 브랜드 주 색의 밝은 톤이다.
- 구조
  - 템플릿 HTML은 그대로 두고 `<body class="style-…">`, 장식 요소(`.deco`, `aria-hidden`), 스타일 파일(`photo.css`·`illust.css`)만 더한다.
  - 글자 크기는 `base.css` 그대로라 표지 최소 크기가 유지된다.
  - 색은 렌더러가 브랜드 색에서 계산한다. photo 바탕은 흰 글자 대비 기준으로 어둡게 맞춘다(노랑 같은 밝은 색도). 광고 배지는 각 바탕에서 보이는 색으로 바꾼다.
- **"AI 생성 이미지" 표기:** 코드로 그린 배경은 생성 이미지가 아니므로 붙이지 않는다. 배경 사진이 있는 장에서만 `labels.ai_generated_image`를 따른다(기존 규칙 그대로).
- **CTA 띠:** 그리지 않는다. 인스타그램 광고의 "더 알아보기" 띠는 플랫폼 기능이다.
- **선택 방법(1차):** 설정 `brand.card_style` 전역 하나.
  - 렌더러는 렌더할 때마다 현재 설정을 읽는다. 대시보드에서 바꾸면 재시작 없이 다음 렌더부터 적용된다.
  - 렌더 캐시 지문에 스타일을 넣어, 스타일을 바꾸면 아직 안 올린 카드는 다시 그린다.
  - 도메인 `Brand`(동결)는 건드리지 않고 설정 쪽 `BrandSettings`에만 필드를 더했다. 덱 JSON 계약도 그대로다.
- **AI 배경 이미지 기본값:** `image_generation` 기본값을 `auto` → `off`로 바꾼다. 어댑터와 설정은 지우지 않는다.
  - `nsm init`에서 OpenAI 키를 새로 넣으면 "AI 배경 이미지를 켤까요?(요금 발생)"를 묻고, 예면 `auto`가 된다. 키만 넣으면 켤 수 있게 하되, 비용은 한 번 확인받는다.
  - 기존 config.yaml에 값이 적혀 있으면 그 값을 따른다(이 PC는 이미 `off`).

## 결과

- 스타일을 바꿔도 비용이 들지 않고, 같은 원고는 늘 같은 카드가 된다.
- `tests/render/`가 지킨다.
  - 스타일 × 템플릿 PNG 크기, 넘침
  - 표기 슬롯이 스타일과 무관함
  - 코드 배경에 AI 표기 없음
  - 글자가 HTML로 있음, CTA 띠 없음
  - 표지 썸네일 가독성(세 스타일)
  - 밝은 브랜드 색 대비
- 어려워진 것: 실제 사진만큼 주제에 맞는 그림은 아니다. 주제에 맞는 사진이 필요하면 검토 화면에서 사진을 올리거나, 키를 넣고 AI 배경을 켠다. 그러면 photo 스타일의 `.has-bg` 뼈대로 그려진다.
- 다시 볼 조건
  - 실제 게시 반응(성과 화면)이 스타일별로 크게 다르면 기본 스타일을 바꾼다.
  - 원고마다 스타일을 고르고 싶어지면 [ADR 0037](0037-per-content-card-style.md)을 진행한다.
