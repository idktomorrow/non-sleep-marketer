# 0029. 댓글 확인 간격: 기본 5분, 설정 화면에서 3~60분

- 상태: 채택 (선웅제 결정 A안, 2026-10-13) · 날짜: 2026-10-13 · 관련: [0028](0028-dashboard-settings.md)

## 배경

댓글 확인(reply 잡)이 10분 고정이라 답이 늦다는 의견이 있었다. 확인 자체는 Aside 브라우저로 게시물 페이지를 여는 일이라 API 비용이 없다. 분류(jev)는 댓글 1건에 약 0.0005센트이고, 답글(Claude)은 1개에 약 0.5센트인데 둘 다 댓글 수에 비례할 뿐 확인 주기와는 무관하다. 대신 주기가 짧으면 두 가지 문제가 있다. 하나는 실계정 페이지를 자주 열어 자동화로 의심받을 위험이고, 다른 하나는 작업 스레드가 하나라 게시·수집이 밀리는 것이다(게시물이 쌓이면 한 번 확인에 몇 분).

## 선택지

- A. 설정값으로 두고 기본 5분, 최소 3분
- B. 10분 고정 유지

## 결정

A. `settings.reply_interval_minutes`(기본 5, 3~60)를 두고 설정 화면에서 고친다. 저장하면 예약을 다시 건다. 지터는 60초로 줄였다(5분 간격에서 3분 지터는 너무 큼).

## 결과

- 대부분 댓글에 5분 안에 답한다.
- 3분 아래로는 둘 수 없다(검사에서 막음).
