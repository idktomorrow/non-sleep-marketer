# 0042. 대시보드 화면 모드: 간단(기본)과 고급, 한 앱 안의 스위치

- 상태: 제안 (배치 C13. 선웅제: 기본은 간단 모드, 간단 "오늘"은 할 일·요약·지금 실행 몇 개, 숨길 메뉴는 자료·실행 기록)
- 날짜: 2026-10-16
- 결정한 사람: 선웅제(기본 모드, 오늘 화면 구성, 숨길 메뉴), 배치 C13 기본값(설정 화면에서 숨길 항목, 저장 위치)
- 관련: [ADR 0025](0025-dashboard-design.md), [ADR 0028](0028-dashboard-settings.md), [ADR 0040](0040-run-log-shows-changes.md)

## 배경

대시보드는 개발하면서 화면이 늘었다. 메뉴 9개, "지금 실행" 버튼 8개, 최근 실행 표, 설정 값 20개 가까이가 한 화면에 있다. 개발자에게는 필요하지만, 매일 원고를 검토하고 댓글에 답하는 일반 마케터에게는 무엇을 봐야 할지 흐려진다.

## 선택지

1. 화면을 두 벌(일반용, 개발자용) 따로 만든다. 같은 기능을 두 번 고쳐야 하고, 한쪽만 고치면 서로 달라진다.
2. **한 앱 안에서 모드 스위치로 보이는 것만 줄인다 (채택)**: 화면과 라우트는 하나다. 간단 모드는 메뉴와 칸 몇 개를 숨길 뿐 기능을 막지 않는다.
3. 사용자 계정·권한으로 나눈다. 로컬 단일 사용자 앱이라 과하다.

## 결정

- 오른쪽 위 "간단 | 고급" 스위치를 모든 화면에 둔다. 모드는 DB 설정 `ui_mode`에 저장해 다시 켜도 유지한다. 처음 값과 알 수 없는 값은 **간단**이다.
- **간단 모드에서 숨기는 것**
  - 메뉴: 자료, 실행 기록. 주소로 들어가면 그대로 열리고, 그 화면에 있는 동안은 탭도 보인다. 알림이 이 화면으로 보낼 수 있어서다.
  - "오늘": 쓸 수 있는 자료 수, "지금 실행" 중 자료 모으기·원고 만들기·댓글 확인을 뺀 나머지, 최근 실행 표.
  - 설정: 활동 시간, 같은 플랫폼 게시 간격, 자료 검색 기간, 댓글 확인 간격(스레드·인스타그램), 금칙 패턴(정규식).
- **간단 모드에 더하는 것:** "오늘"에 자료 올리기 칸. 올리면 "오늘"로 돌아와 결과를 보여 준다. 업로드의 `next` 값은 `/`일 때만 따르고, 다른 값이면 자료 화면으로 보낸다(열린 리다이렉트 방지).
- 숨긴 설정 칸은 폼에서 빼지 않고 `hidden`으로 감춘다. 저장할 때 지금 값이 함께 가므로, 간단 모드에서 저장해도 세부 값이 바뀌지 않는다.
- 간단 모드로 바꿀 때 메뉴에서 사라지는 화면(자료, 실행 기록)에 있었으면 "오늘"로 보낸다. 그 밖에는 있던 화면에 머문다.
- 남기는 것: 할 일(계속 0건 포함), 오늘 게시·대기·비용, 페르소나·자동 게시 스위치, 검토·게시 대기·댓글·성과·주간 리포트·설정, 알림함.

## 결과

- 일반 사용자는 메뉴 7개와 매일 쓰는 버튼만 본다. 개발자는 스위치 한 번으로 지금까지와 같은 화면을 본다.
- 화면이 하나라 기능을 고칠 때 두 번 고치지 않는다. 라우트 테스트도 그대로다.
- 어려워진 것
  - 화면에 새 칸을 넣을 때 "간단 모드에도 보일까"를 정해야 한다. 기본은 고급에만 넣는다.
  - 모드는 PC 하나에 하나다. 같은 대시보드를 두 사람이 다른 모드로 볼 수 없다.
- 다시 볼 조건
  - 일반 사용자 피드백에서 숨긴 칸(예: 자료 화면)을 자주 찾으면 간단 모드에 다시 넣는다.
  - 사용자가 여럿이 되면 모드를 브라우저(쿠키)별로 옮긴다.
