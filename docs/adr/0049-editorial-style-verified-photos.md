# 0049. 사진 우선형(editorial) 카드 스타일: 사람이 확인한 사진만 카드에 쓴다 (ADR 0045·0036 수정 제안)

- 상태: 제안 (배치 S10, 서브 제안 PR. 메인 합의 전에는 머지하지 않는다)
- 날짜: 2026-10-20
- 결정한 사람: 서브(제안 초안). 사진 사용 범위는 메인이 정한다
- 관련: [0036](0036-code-drawn-card-styles.md)(코드로 그린 배경), [0045](0045-image-materials.md)(카드에 사진 안 넣음), [0035](0035-cover-readable-at-threads-thumbnail.md)(표지 최소 글자 크기), [0043](0043-virtual-person-badge-cover-and-outro.md)(배지 위치), [0037](0037-per-content-card-style.md)(원고별 스타일), [0024](0024-card-editor-scope.md)(장별 배경 올리기)

## 배경

굿즈·협업·행사 소식 계정에서 반응이 좋은 카드는 "큰 원본 사진 + 짧은 제목 두 줄"로 시작하고, 본문도 사진 위에 설명 패널을 올리는 모양이다(2026-10-20 사용자 기획, 참고 화면 15장). 지금 세 스타일은 배경을 코드로 그리고(ADR 0036), 올린 이미지는 글로만 옮겨 쓴다(ADR 0045 "카드에 사진을 넣는 쪽은 하지 않음"). 그래서 사진이 주인공인 카드를 만들 길이 없다.

한편 장별 `background`는 덱 JSON 계약에 이미 있고, 검토 화면에서 장별 사진 올리기(ADR 0024)도 이미 있다. 사진을 깔 수 있는 자리는 있는데, 그 위에 글을 "사진이 보이게" 얹는 스타일이 없는 상태다.

## 선택지

1. **사진 금지 유지(ADR 0045 그대로)**: 저작권 위험이 없다 / 사진 중심 카드를 만들 수 없고, 사용자가 올린 사진(직접 찍은 매장 사진, 자사 상품 사진)도 못 쓴다.
2. **기사·공식 페이지 사진을 자동으로 깔기**: 손이 가장 덜 든다 / 굿즈 사진의 캐릭터 저작권, 인물 사진의 초상권을 프로그램이 판단하지 못한다. 자동 게시 경로에 남의 사진이 섞인다.
3. **사람이 확인한 사진만 쓰는 스타일 추가 (채택)**: 사진은 사람이 올리거나(장별 배경 올리기) 사람이 "쓰기"를 누른 것만 카드에 들어간다. 자동으로 구한 사진은 후보일 뿐이다(2차, 배치 S11 제안) / 사진이 없으면 모양이 단순한 종이색 카드가 된다.

## 결정

3번. 네 번째 카드 스타일 `editorial`(사진 우선형)을 더하고, ADR 0045의 "카드에는 이미지를 넣지 않는다"를 "**프로그램이 고른 이미지는 넣지 않는다. 사람이 올리거나 확인한 사진은 장별 `background`로 넣을 수 있다**"로 고치자고 제안한다.

- **모양**
  - 표지(사진 있음): 사진 전체, 아래 절반만 어둡게. 왼쪽 아래에 부제를 작은 키커로, 그 아래 제목 두 줄(흰 글자). 이름·가상인물 배지·광고 배지 자리는 그대로(ADR 0043).
  - 본문(사진 있음): 사진 전체 + 아래 흰 설명 패널(소제목·본문·글머리). 보통 길이면 패널은 카드 높이의 35% 아래라 사진이 주인공이다.
  - 리스트·비교(사진 있음): 사진을 흐리고 밝게 깔고 흰 카드에 진한 글자.
  - 마무리(사진 있음): 사진을 어둡게 깔고 가운데 흰 "팔로우 카드"(이름·핸들·CTA), 아래 출처.
  - 사진 없음: 종이색 바탕 + 얇은 테두리 카드. 도형 장식은 없다.
- **지키는 것**: 글자는 전부 HTML(이미지에 굽지 않음). 표기 슬롯(`data-label`, `data-sources`, `data-page`)과 표지 최소 글자 크기(제목 88px, 부제 48px, 이름 38px, 배지 34px, ADR 0035)는 다른 스타일과 같다. 키커는 부제 슬롯을 그대로 쓰므로 최소 48px이다(34px 안은 폐기). CTA 띠는 그리지 않는다.
- **"AI 생성 이미지" 표기**: 규칙 그대로. 사람이 올린 사진은 `labels.ai_generated_image`가 꺼져 있으면 표기하지 않고, AI 배경(`media/bg-*.png`)이면 기존처럼 켜진다.
- **선택 방법**: 설정 `brand.card_style`에 `editorial`을 더한다(전역 하나, ADR 0036과 같은 방식). 설정 화면 견본은 동봉한 **합성 견본 사진**(`nsm/templates/samples/sample-photo.jpg`, Pillow로 그린 저작권 없는 그림)을 화면에 보이는 두 장(표지·설명 패널 본문)에 깔아 보여 준다. 사진 파일이 바뀌면 견본 캐시 키와 썸네일 주소도 바뀐다.
- **저작권·초상권**: 프로그램은 판단하지 않는다. 설정 화면과 사용자 안내에 "직접 찍었거나 쓸 권리가 있는 사진만, 연예인 등 인물 사진은 공식 보도자료·소속사 공개 이미지만"을 적는다. 자동으로 구한 사진을 후보로 보여 주는 일은 배치 S11 제안에서 다루고, 그때도 사람이 "쓰기"를 눌러야 카드에 들어간다.

## 보강(2026-10-20 저녁, 사용자 레퍼런스 7장 + 조사)

사용자가 키치·밈 톤의 굿즈 소식 계정(코코네코 등)을 참고로 주며 "카드 내용에 맞는 몽글몽글한 일러스트"를 원했다. 조사(2026 그래픽 트렌드: 스티커·컷아웃, 키드코어, 의도 있는 맥시멀리즘, 캐러셀 표지 티저)와 함께 다음을 더했다.

- **자체 몽글 캐릭터**(`_parts.html` `kawaii` 매크로, SVG): 콩 모양 흰 몸, 새싹, 콩알 눈, 홍조. **치이카와 같은 저작권 캐릭터를 그리지 않는다**(ADR 0036). 다이컷 스티커처럼 흰 테두리 두 겹.
- **카드 내용에 맞는 소품·장면**(`nsm/render/mascot.py` `pick_prop`): 덱 글의 낱말로 고른다. 항공·기내 → 조종사 모자 + 비행기·구름, 커피 → 머그컵 + 원두, 극장판 → 팝콘 + 필름, 굿즈 출시 → 선물 가방 + 색종이, 행사 → 별, 없으면 손 흔들기. 사진이 있는 장에서는 사진이 장면이라 캐릭터만 얹는다.
- **배치 규칙**: 캐릭터는 가상인물 배지가 있는 표지·마지막 장에만(ADR 0043·0046), 가운데 장에는 소품 아이콘만.
- **키치 바탕**: 종이색 → 브랜드 파스텔 크림(`--illust-bg` 기반), 키커는 형광 칩, 사진 없는 본문은 점선 메모 상자, 표지에 "WHAT'S NEW" 장식 글자.
- 테스트: 소품 고르기 단위 테스트, 캐릭터가 표지·마지막 장에만 2개·소품 아이콘·장면이 사진 유무에 따라 바뀌는지, 순백 사진 대비는 글자색을 실제로 읽어 잰다. `color-mix()` 결과(`color(srgb …)`)를 대비 테스트가 읽도록 고쳤다.
- 후속: 밈 2단 장(사진 두 장 + 검은 라벨 + 말풍선)은 덱 계약에 장이 필요해 S12 ADR에 적는다. "키치·밈"을 관심 분야 프리셋으로 넓히는 건 S11 뒤 별도 제안.

## 결과

- 사진을 올리면 사진이 주인공인 카드가 나온다. 사진이 없으면 지금처럼 코드 배경(종이색)으로 떨어져 게시가 막히지 않는다.
- `tests/render/test_editorial_style.py`가 지킨다: 사진 있음/없음 × 보통/극단 글 PNG 크기·넘침, 패널·팔로우 카드는 사진이 있을 때만, 표기 슬롯 동일, 사진 위 표지 썸네일 가독성, 패널 높이 35% 이하, 흰 패널 글자 대비 4.5 이상. 기존 스타일 매트릭스(`test_card_styles.py`)에도 포함.
- 실제 사진 확인(2026-10-20): Wikimedia Commons CC0 사진(기념품 가게의 봉제 인형 진열대, 3:4)으로 표지·본문·마무리를 렌더해 제목이 사진 아래쪽 진열대 위에 얹혀도 읽히는지 확인했다. 사진 가운데에 피사체가 있으면 표지 제목·설명 패널이 피사체 아랫부분을 가린다. 사진 초점(크롭 기준점) 조정은 이 스타일 범위 밖이고, 검토 화면에서 사진을 바꾸는 것으로 대신한다.
- 어려워진 것: 사진 없이는 photo·illust보다 심심하다. 상품 2~4개 그리드·일정 패널 같은 장은 덱 JSON에 자리가 없어 이 스타일로는 못 그린다(배치 S12 계약 변경 제안).
- 다시 볼 조건: 메인이 사진 사용 범위를 다르게 정하면(예: 자사 사진 폴더만) 그 범위에 맞춰 설정 안내와 S11 후보 수집을 줄인다. 원고별 스타일(ADR 0037)이 들어오면 editorial은 "사진이 있는 원고에만" 고르는 선택지가 된다.
