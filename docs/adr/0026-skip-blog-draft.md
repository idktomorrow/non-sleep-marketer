# 0026. 블로그를 게시하지 않으면 블로그 원고를 만들지 않는다

- 상태: 채택 (선웅제 결정, 2026-10-13) · 날짜: 2026-10-13 · 관련: 이슈 #43, [0016](0016-drop-naver-blog-publishing.md)

## 배경

네이버 블로그 게시를 MVP에서 뺐지만(ADR 0016), 생성기는 원고마다 블로그 제목과 1,500~2,500자 블로그 본문을 계속 만들었다. 아무도 쓰지 않는 글에 Claude 출력 비용이 들었다. `GeneratedContent.blog_title`·`blog_markdown`은 동결 계약이라 필드를 빼려면 두 사람이 합의한 PR이 필요하다.

## 선택지

1. 필드를 모델에서 지운다. 동결 계약 변경이라 팀원 합의, 호출부·드라이런 어댑터·테스트까지 함께 고쳐야 한다.
2. 필드는 두고 빈 문자열로 채운다. 생성기가 블로그 칸을 요청하지 않는다.

## 결정

2번. 설정의 `enabled_platforms`에 `naver_blog`가 없으면 생성기가 구조화 출력 스키마와 시스템 프롬프트에서 블로그 칸을 빼고, 결과의 두 필드는 빈 문자열이다. 검토 화면은 블로그 원고가 비어 있으면 그 칸을 숨긴다. 모델(`nsm/domain/models.py`)은 바꾸지 않는다.

## 결과

- 원고 1건당 출력 토큰이 줄어든다(블로그 본문만큼).
- 나중에 블로그 게시를 다시 켜면 `enabled_platforms`에 `naver_blog`를 넣는 것만으로 블로그 원고가 다시 만들어진다. 이미 만든 원고에는 블로그 글이 없다.
- 필드를 완전히 없애는 일은 동결 계약을 다시 볼 때 함께 정한다.
