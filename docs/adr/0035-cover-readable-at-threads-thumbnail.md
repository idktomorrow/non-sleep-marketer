# 0035. 카드 표지는 스레드 피드 썸네일(약 21%) 크기에서도 읽히게 키운다

- 상태: 제안 (PR 리뷰에서 전후 PNG를 보고 선웅제 승인)
- 날짜: 2026-10-14
- 결정한 사람: 선웅제(리뷰에서 승인 예정), 배치 S-γ 기본값
- 관련: 이슈 #23, [0019](0019-label-wording-and-placement.md), [quality-checklist](../quality-checklist.md) 5절

## 배경

- **썸네일 크기 실측.** 스레드 피드와 글 화면은 카드 이미지를 224×280 CSS 픽셀로 보여 준다. 2026-10-14 threads.com에서 운영 계정 글로 쟀고, 화면 폭 1440px에서도 같았다. 원본 1080×1350의 약 21%다. Meta는 표시 폭을 공식으로 밝히지 않는다. 외부 크기 가이드는 1080×1350(4:5) 업로드만 권한다.
- **기존 표지를 이 비율로 줄인 크기**
  - 제목: 112px → 23px. 길어서 최소 64px까지 줄면 → 13px
  - 부제: 46px → 9.5px. 최소 30px까지 줄면 → 6px
  - 이름: 30px → 6px
  - 가상인물 배지: 26px → 5.4px
- **실제 원고에서 본 문제.** 10-13 원고의 제목 "극장판 흥행에\n\n게임도 역주행"이 빈 줄 때문에 줄 사이가 한 줄 이상 벌어져 그려졌다.

## 선택지

1. **그대로 둔다:** 디자인 변경이 없다 / 피드에서 부제와 표기 배지가 거의 안 읽힌다.
2. **표지 글자만 키운다**
   - 장점: 제목·부제·이름·배지를 키워도 표지에는 위쪽 빈 공간이 넉넉해 넘치지 않는다. 본문 장은 피드에 작게 보이지 않으므로 그대로 둔다.
   - 단점: 표지가 조금 더 꽉 차 보인다.
3. **표지 구성을 바꾼다(제목을 위로, 더 큰 글자):** 효과는 가장 크다 / S8(카드 스타일)과 겹치는 큰 디자인 변경이다.

## 결정

2번. 썸네일 기준 최소 크기(실측 비율 224/1080)를 정했다.

| 요소 | 크기 | 썸네일에서 |
|---|---|---|
| 제목 | 112px, 줄어도 최소 88px | 18px 이상 |
| 부제 | 46px → 60px, 최소 48px | 10px 이상 |
| 이름 | 표지에서 38px | 약 8px |
| 가상인물 배지 | 표지에서 34px | 약 7px |
| 광고 배지 | 표지에서 40px | |

표지 제목의 빈 줄은 한 줄바꿈으로 합친다(`one_break` 필터).

## 결과

- **회귀 테스트(`tests/render/`)**
  - 템플릿 3종 × 일반·극단 입력에서, 글자 맞춤(nsmFit)이 끝난 뒤의 표지 글자 크기가 위 최소값 이상인지 검사한다.
  - 빈 줄이 든 제목이 2줄로 그려지는지 검사한다.
- 템플릿 파일이 바뀌어 렌더 지문이 달라진다. 이미 만든 원고도 다음 게시 때 카드를 새로 그린다.
- **다시 볼 조건**
  - 스레드가 피드 이미지 크기를 바꿀 때
  - S8에서 사진·일러스트 표지가 생길 때. 배지는 그림 옆으로 가야 한다(ADR 0019).
