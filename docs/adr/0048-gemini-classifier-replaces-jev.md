# 0048. 분류기는 Gemini 무료 구간을 기본으로, jev(MotherDuck)는 뺀다

- 상태: 제안 (배치 C27. 선웅제가 정한 것: 돈이 나가지 않는 쪽, jev·MotherDuck은 아예 제거, Gemini 무료 구간 채택)
- 날짜: 2026-10-20
- 결정한 사람: 선웅제(방향·제거), 배치 C27 기본값(모델, 묶음 크기, 대체 순서)
- 관련: [ADR 0003](0003-classifier-jev-and-claude.md)(대체됨), [ADR 0011](0011-keyword-classifier-fallback.md)(키 없을 때 낱말 분류기)

## 배경

2026-10-20 00:29 자료 수집에서 31건 전부 분류 실패. 오류는 "Your MotherDuck trial has ended". jev는 TypeSafe의 모델을 MotherDuck 안에서 `prompt_jev()`로 부르는 구조라, 체험 기간이 끝나면 요금제(Lite: 월 요금 $0이지만 호출은 입력 토큰 과금, 결제 수단 등록)가 필요하다. 사용자는 "돈이 나가지 않는 쪽"을 원했다.

후보를 운영 DB 백업의 **실제 자료 294건(jev 판정 있음) + 댓글 9건**으로 비교했다.

| 후보 | 비용 | 관련성 jev 일치 | 댓글 | 비고 |
|---|---|---|---|---|
| Laya 다국어(내 PC, 3.2억) | 0 | 27~51% | 3/9 | 무관한 낱말까지 "관련". 한국어가 약함. 탈락 |
| **Gemini 3.5 Flash-Lite(무료 구간)** | 0(한도 안) | 10건 묶음 88.8% → 1건씩 + 지시문 보강으로 불일치 33건 중 25건 해소, **약 97%** | **9/9** | 남은 불일치 8건은 사람이 봐도 애매한 글 |
| Claude Haiku | 월 약 200원 | (기존 동등 구현) | | 유료 |
| 내 PC 범용 LLM(Ollama 4B) | 0 | 미실험 | | Gemini가 되어 실험하지 않음 |
| 낱말 규칙 | 0 | 낮음 | 위험 | 키가 하나도 없을 때만 |

## 선택지

1. jev를 남기고 자동 선택 순서만 바꾼다 → 체험이 끝난 토큰이 남아 있으면 또 조용히 실패한다. 안 쓰는 코드·문서가 거짓말을 한다.
2. **jev·MotherDuck을 제거하고 Gemini를 기본으로(채택)** → 설정·마법사·점검·문서가 한 번에 단순해진다. 다시 쓰려면 git 기록에 있다.

## 결정

- **제거**: `nsm/adapters/classifier/jev.py`, `motherduck_token` 키, `nsm init`의 토큰 질문, `nsm doctor --live`의 jev 점검, 가격표의 jev 줄, 설정값 `classifier: jev`. 예전 설정 파일의 `jev`는 `auto`로 읽는다.
- **Gemini 분류기**(`nsm/adapters/classifier/gemini.py`)
  - REST `generateContent`를 httpx로 직접 부른다. 새 의존성 없음. 키는 keyring `gemini_api_key`(환경 변수 `NSM_GEMINI_API_KEY`/`GEMINI_API_KEY`/`GOOGLE_API_KEY`도 됨).
  - 모델은 설정 `models.gemini`(기본 `gemini-3.5-flash-lite`). 무료 구간에서 실제로 되는 것을 확인한 모델이다.
  - 무료 구간 한도(분당 약 15회) 때문에 **10건씩 한 요청**에 묶는다. 429는 20·40·60초 기다렸다 다시 보내고, 그래도 안 되면 오류로 넘긴다.
  - 비용은 기록하지 않는다(0원). 유료로 바꾸면 그때 기록한다.
- **선택 순서**(`settings.classifier`): `auto`(기본) = Gemini 키 → Claude 키 → 낱말 규칙. `gemini`·`claude`·`keyword`로 고정할 수도 있다.
- **자동 대체**: 고른 분류기가 호출에 실패하면 다음 분류기로 넘어가고(그 실행 안에서), 처음 넘어갈 때 알림을 보낸다. 분류 기록에는 실제로 판정한 분류기 이름을 적는다. 2026-10-20처럼 "분류기 전체 실패 → 자료 0건"이 조용히 지나가지 않게.
- **지시문 보강**: 관련성 지시문에 "관심 주제의 흥행·판매·품절·행사 뉴스 기사와 공식 소식 정리는 relevant다"를 더한다. Gemini가 치이카와 흥행 기사를 "정보성 글이 아님"으로 보던 것이 이 한 줄로 해결됐다. 모든 분류기가 같은 지시를 쓴다.

## 결과

- 분류 비용 0원. 자료 60건/일, 댓글 수 건/일이면 하루 한도(약 1,500회)의 10% 미만.
- 어려워진 것
  - 무료 구간은 보낸 글이 구글 모델 학습에 쓰일 수 있다. 보내는 것은 공개 뉴스·블로그 글과 공개 댓글이다. 사용자가 이를 알고 선택했다.
  - 무료 한도·정책은 구글이 바꿀 수 있다. 바뀌면 `classifier: claude`(월 200원 안팎)로 돌리거나, OpenAI 호환 규격의 다른 무료 API·내 PC 모델로 어댑터를 더한다.
  - 무료 구간이라 분당 호출이 적다. 묶음 호출로 해결했고, 댓글은 건수가 적어 영향이 없다.
- 다시 볼 조건
  - 429가 하루에 여러 번 나오면 묶음을 키우거나 Claude로 바꾼다.
  - 무료 구간이 없어지면 ADR을 다시 쓴다.
