# 0052. 사람 칸에는 돈·약속이 걸린 댓글만: 불만은 2차 판정, 숨기기 없는 플랫폼의 스팸은 자동 처리

- 상태: 제안 (배치 C32. 선웅제 결정: 스팸·소식 반응은 자동, 브랜드·거래·환불·법적 불만만 사람에게)
- 날짜: 2026-10-24
- 관련: [ADR 0008](0008-autopublish-guardrails.md)(안전장치), [contracts 4절](../contracts.md), [ADR 0047](0047-replies-grounded-in-post-sources.md)(답글 근거)

## 배경

"사람이 답할 댓글" 칸에 2026-10-21 들어온 3건: 되팔이 홍보(스팸 추정), "😨"(불만), "업자들이 문제 아닌가요?"(불만). 셋 다 사람이 버튼을 눌러야 했지만 사람이 할 일이 아니었다. 스팸은 답하지 않는 게 정답이고, 뒤의 둘은 우리 브랜드 불만이 아니라 **소식에 대한 반응**이라 페르소나가 공감하면 그만이다. 완전 자동이라는 약속에 비해 사람 손이 너무 자주 필요했다.

반면 가격·환불·법적 문제, 그리고 우리 브랜드·제품·거래에 대한 불만은 가상 인물이 "환불해 드릴게요"처럼 약속이 되는 말을 하거나 틀린 톤으로 답하면 손해가 커서(공정위 표기 의무까지 걸려 있다) 사람 승인이 설계의 핵심이다(ADR 0008).

## 선택지

1. 전부 지금처럼 사람에게 → 하루 몇 번씩 사람 손. 완전 자동 약속과 어긋남.
2. 불만을 전부 자동 답글 → 브랜드 불만에 가상 인물이 사과·약속을 할 위험.
3. **스팸은 자동 처리, 불만은 2차 판정으로 가르기(채택)**. 애매하면 사람 쪽으로.

## 결정

- `decide_comment(..., complaint_scope)`: 불만(complaint)은 2차 판정 결과가 `topic_reaction`일 때만 자동 답글(하루 한도·답글 가능 여부는 그대로). `brand_complaint`이거나 판정이 없으면(None) 사람에게. 가격·환불·법적 문제는 변함없이 사람에게.
- 2차 판정(`reply._complaint_scope`): 댓글 분류기(Gemini, 0원)에게 "불만의 대상이 이 계정·브랜드·제품·주문·배송·응대인가(brand_complaint), 소식·현상·제3자에 대한 아쉬움·분노·걱정인가(topic_reaction)"를 브랜드 이름과 함께 묻는다. 라벨이 둘 중 하나가 아니거나 신뢰도 < 0.6이거나 호출이 실패하면 None → 사람에게(안전한 쪽).
- 소식 반응 답글의 규칙("공감만, 사과·보상·약속 금지, 남 비난 금지")은 답글 **시스템 지시**에 둔다. 자료(데이터) 쪽에 지시를 섞지 않는다(포트 `generate_reply`는 동결이라 별도 인자가 없고, 여기까지 오는 불만은 2차 판정을 통과한 소식 반응뿐이다).
- 2차 판정은 자동 답글이 가능할 때만 묻는다(1차 신뢰도 ≥ 0.6, 답글 가능 플랫폼, 하루 한도 안). 어차피 사람에게 갈 댓글에 호출을 쓰지 않는다. 분류기가 라벨을 못 고르면 마지막 라벨로 떨어지므로 라벨 순서를 `(topic_reaction, brand_complaint)`로 둬 안전한 쪽으로.
- 1차 신뢰도가 낮으면 숨김·무시도 하지 않고 사람에게(스팸으로 잘못 본 환불 문의가 조용히 버려지지 않게). 넘김·숨김 줄은 댓글 화면에 사유를 보여 준다.
- 스팸: 숨기기가 되는 플랫폼(스레드)은 전처럼 숨김. 안 되는 플랫폼(인스타그램)은 사람에게 넘기던 것을 **답하지 않고 "넘김"으로 기록**(사유 "스팸 추정(답하지 않고 자동 처리)"). 댓글 화면에서 사유로 확인할 수 있다.

## 결과

- 사람 칸에는 브랜드·거래 불만, 가격·환불, 법적 문제, 분류 불확실, 금칙어·미확인 답글만 남는다. 10-21 사례 3건은 모두 자동으로 끝난다.
- 어려워진 것
  - 2차 판정이 "소식 반응"이라고 오판하면 브랜드 불만에 공감만 하는 답글이 달린다. 지시가 "애매하면 brand_complaint"이고 신뢰도 하한이 있어 사람 쪽으로 기운다. 답글에는 사과·약속이 금지돼 있어 오판해도 약속은 생기지 않는다.
  - 인스타그램 스팸은 화면에 그대로 남는다(숨기기 불가). 전에도 사람이 할 수 있는 건 없었다.
- 다시 볼 조건: 자동 답글이 달린 불만 댓글을 1주일 보고 오판이 보이면 신뢰도 하한을 올리거나 brand 쪽 사례를 지시에 더한다.
