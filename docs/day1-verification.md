## 표기 문구 원문 대조

원문은 법제처 국가법령정보센터(DRF)와 공정위 보도자료에서 직접 확인했다.

| 항목 | 결과 |
|---|---|
| 심사지침 가상인물 표시 예시 | 「추천·보증 등에 관한 표시·광고 심사지침」(공정위 예규 제499호, 2026-06-01 시행) Ⅴ.5: 게시물은 "제목 또는 첫 부분에 '인공지능(AI)을 기반으로 생성된 가상인물이 포함된 게시물입니다', '가상인물(…) 포함' 등의 문구". 보도자료 예시는 "AI를 기반으로 생성된 가상 인물이 포함된 게시물입니다." 기존 코드 문구는 보도자료와 띄어쓰기만 다르다. **예규 원문 문구로 확정** |
| 표시 위치 | 글: 제목 또는 첫 부분, 본문과 구분, '더보기'에 가려지면 안 됨. 사진·동영상: "가상인물이 등장하는 동안 가상인물과 근접한 위치", 배경과 구분되는 색. 광고: '#광고'는 명확한 문구로 인정. 사진 매체는 사진 안 또는 글 첫 부분, 해시태그면 **첫 번째 해시태그**, "여러 해시태그 사이"는 부적절 |
| AI 기본법 시행령 | 법 제31조②③, 시행령 제23조: 생성형 결과물은 사람이 인식할 수 있거나 기계가 판독할 수 있는 방법으로 표시. 실제와 구분하기 어려운 결과물은 이용자가 명확히 인식하도록 표시. 의무 주체는 '인공지능사업자'. 과태료는 제31조①(사전 고지) 위반에만 있음. 계도기간은 법령에 없고 정부 발표(1년 이상)뿐 |
