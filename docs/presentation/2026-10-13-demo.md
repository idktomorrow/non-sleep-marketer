# 논슬립 마케터 발표 (2026-10-13, 5~7분)

> 작성: 2026-10-13 · 기준 버전: `v0.3-mvp` · 관련: [README](../../README.md) · [PRD](../PRD.md) · [architecture.md](../architecture.md)

## 발표 전 준비 (10분)

1. `uv run nsm run`을 켜 두고 브라우저에 http://127.0.0.1:8765 를 열어 둔다.
2. 검토 대기에 원고가 1건 이상 있는지 확인한다. 없으면 개요의 "지금 실행"에서 수집 → 원고 생성을 미리 눌러 둔다.
3. 스레드 앱이나 웹에서 테스트 계정 프로필을 미리 열어 둔다.

## 슬라이드 10장과 대본

### 1. 제목: 논슬립 마케터

"자는 동안에도 일하는 AI 마케터입니다. 제 PC에 설치해 두면 AI 가상 인플루언서가 인스타그램과 스레드를 대신 운영합니다."

### 2. 문제

"1인 브랜드나 작은 팀은 SNS를 꾸준히 해야 하는데, 자료 찾기, 카드뉴스 만들기, 플랫폼마다 올리기, 댓글 답하기, 성과 정리가 전부 사람 시간에 묶여 있습니다. AI로 만들면 내용이 맞는지, AI·가상인물·광고 표기 의무를 지키는지도 걱정입니다."

### 3. 해결

"프로그램 하나가 이 흐름을 돕니다. 자료 수집 → 글과 카드뉴스 생성 → 게시 → 댓글 답글 → 주간 결산. 사람은 대시보드에서 검토하고 승인만 합니다."

### 4. 하루 일과

"하루 두 번 자료를 모으고, 하루 최대 3건(인스타 1, 스레드 2) 원고를 만들고, 5분마다 댓글을 확인하고, 월요일에 주간 리포트를 씁니다. 활동 시간은 제가 정합니다."

### 5. 데모 (라이브)

순서: 대시보드 개요 → 검토 대기 클릭 → 카드 편집 화면에서 문구 하나 고치고 미리보기 → 승인 → 스레드 또는 인스타 테스트 계정에 올라간 글.

"원고와 카드는 AI가 만들고, 저는 보고 고치고 승인합니다. 승인하면 Aside 브라우저가 실제 계정에 올립니다."

### 6. 안전장치

"처음 몇 건은 반드시 사람이 승인합니다. 출처 없는 주장, 금칙어, 민감한 댓글은 자동 처리하지 않고 사람에게 넘깁니다. 하루 게시 수와 비용 상한(3달러)이 걸려 있어 폭주하지 않습니다. 가상인물·광고·AI 생성 표기는 공정위 지침과 AI 기본법 원문을 대조해 자동으로 붙입니다."

### 7. 구성 (기술은 이 한 장만)

"글은 Claude, 분류는 jev, 게시는 Aside 브라우저, 수집은 Playwright, 카드뉴스는 HTML 템플릿을 이미지로 찍어 만듭니다. 데이터와 대시보드는 전부 제 PC 안에만 있습니다."

### 8. 만든 방법

"3일 동안 2명이 Claude Code와 함께 만들었습니다. 작업을 '배치' 단위로 나눠 배치 하나가 세션 하나, PR 하나가 되게 했고, 배치마다 코드 리뷰를 돌렸습니다."

| 머지된 PR | 28 |
| 설계 결정 기록(ADR) | 29 |
| 자동 테스트 | 380개 이상 |

### 9. 비용

"Claude API가 하루 20센트 안팎, 한 달 몇 달러입니다. 분류(MotherDuck)는 무료, Aside는 기존 Claude 구독을 씁니다."

### 10. 한계와 다음

"공식 API가 아니라 브라우저 자동화라 계정 제재 위험이 있어 테스트 계정으로만 돌립니다. 네이버 블로그 게시는 뺐습니다. 각자 PC에 설치하는 형태라 여러 사람이 같이 쓰는 서비스는 아직 아닙니다. 다음은 팀원이 맡은 계약 테스트, 품질 점검, 카드 디자인 스타일이고, 끝나면 v0.4가 됩니다."

## 예상 질문과 답

- **계정이 정지되면?** 테스트 계정으로 돌리고, 하루 게시 수를 제한하며, 로그인이 풀리면 멈추고 알림을 보낸다.
- **글 내용이 틀리면?** 모든 주장은 수집한 자료에 출처가 연결되어야 하고, 연결이 안 되면 사람 검토로 간다.
- **왜 공식 API를 안 썼나?** 인스타·스레드 공식 API는 승인 절차와 제약이 커서 MVP에서는 브라우저 자동화를 택했다. 구조상 어댑터만 바꾸면 공식 API로 갈 수 있다.
- **다른 사람도 쓸 수 있나?** 저장소를 받아 설치하고 본인 키와 계정을 넣으면 된다. [사용설명서](../user-guide.md) 참고.
- **비용이 폭주하면?** 하루 3달러 상한에서 자동으로 멈춘다.
