# 용어집

이 프로젝트에서 자주 쓰는 말. 배치에서 새 개념이 나오면 추가합니다.

| 용어 | 뜻 | 이 프로젝트에서 |
|---|---|---|
| **ADR** | Architecture Decision Record. 설계 결정 하나를 배경·선택지·결정·결과로 적은 짧은 문서 | `docs/adr/` |
| **배치** | 이슈 여러 개를 묶어 한 세션·한 브랜치·한 PR로 끝내는 작업 단위 | `docs/process.md` |
| **DoD** | Definition of Done. "끝났다"고 말하기 위한 조건 목록 | `CLAUDE.md` |
| **포트(port)** | 엔진이 바깥 세계와 대화하는 인터페이스. 무엇을 할 수 있는지만 정의 | `nsm/ports/` (`typing.Protocol`) |
| **어댑터(adapter)** | 포트를 실제로 구현한 것. 같은 포트에 여러 구현을 갈아끼움 | 인스타 어댑터, 드라이런 어댑터, 가짜 어댑터 |
| **헥사고날 아키텍처** | 포트와 어댑터로 핵심 로직을 외부 의존(브라우저, API, DB)에서 떼어내는 설계 | 엔진은 Aside·Claude를 직접 모름 |
| **드라이버** | 브라우저를 실제로 조작하는 얇은 층. 어댑터가 사용 | Aside, Playwright |
| **드라이런(dry run)** | 실제로 실행하지 않고 결과만 만들어 보는 모드 | 게시 대신 `preview/` 폴더에 저장 |
| **가짜(fake)** | 테스트 전용 구현. 호출을 메모리에 기록하고 정해진 응답을 돌려줌 | `tests/fakes/` |
| **픽스처(fixture)** | 테스트가 쓰는 고정 입력 데이터나 준비 코드 | `tests/fixtures/`, `conftest.py` |
| **계약 테스트** | 같은 시나리오를 여러 구현(어댑터)에 돌려 모두 포트의 약속을 지키는지 확인 | `tests/contracts/` |
| **capability** | 어댑터가 할 수 있는 일의 목록. 못 하는 일은 정책이 다른 경로로 처리 | 숨기기 미지원 → 사람에게 넘김 |
| **잡(job)** | 스케줄러가 정해진 주기로 호출하는 작업 하나 | collect, publish, reply … |
| **지터(jitter)** | 주기에 섞는 무작위 지연. 봇처럼 정확한 간격을 피함 | 댓글 확인 10분 ±3분 |
| **멱등성(idempotency)** | 같은 작업을 두 번 해도 결과가 한 번 한 것과 같은 성질 | 재시작 시 이중 게시 방지 |
| **상태 머신** | 허용된 상태 전이만 가능하게 만든 규칙 | 콘텐츠 draft → … → published |
| **claim** | 콘텐츠 안의 사실 주장 하나와 그 출처 자료 ID의 짝 | 자동 게시 조건 |
| **보호 모드** | 설치 직후 첫 20건을 무조건 사람이 검토하는 모드 | ADR 0008 |
| **쿼터** | 하루에 허용되는 최대 횟수 | 플랫폼별 게시 수 |
| **DuckDB** | 파일 하나로 동작하는 무료 오픈소스 DB. 한 프로세스만 쓰기 가능 | `data.duckdb`, ADR 0006 |
| **MotherDuck / jev** | DuckDB 클라우드 서비스 / 그 안에서 SQL로 부르는 분류 전용 모델. 체험 종료로 2026-10-20에 뺌 | ADR 0003 → 0048 |
| **Gemini 무료 구간** | 구글 Gemini API의 무료 사용 한도(Flash 계열, 분당·하루 요청 수 제한). 자료·댓글 분류에 씀 | 분류기, ADR 0048 |
| **keyring** | OS 자격 증명 저장소(Windows 자격 증명 관리자)를 쓰는 Python 라이브러리 | API 키 보관 |
| **uv** | 빠른 Python 패키지·가상환경 관리 도구. `uv.lock`으로 버전 고정 | `uv sync`, `uv run` |
| **ruff** | Python 린터·포매터 | DoD 1번 |
| **HTMX** | HTML 속성만으로 서버와 부분 갱신을 하는 작은 JS 라이브러리 | 대시보드 버튼 동작 |
| **Conventional Commits** | `feat(scope): 설명` 형식의 커밋 메시지 규칙 | 모든 커밋 |
