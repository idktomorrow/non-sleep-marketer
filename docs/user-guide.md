## 1. 시작 전에

### 무엇을 하는 도구인가

내 PC에서 계속 켜 두는 프로그램입니다. 내가 정한 "AI 가상 인플루언서" 페르소나가 자료를 모으고, 카드뉴스와 글을 만들어 인스타그램·스레드·네이버 블로그에 올리고, 내 게시물의 댓글에 답하고, 성과를 대시보드로 보여줍니다. 민감한 것(출처가 불확실한 글, 불만·환불·법적 댓글)은 자동 처리하지 않고 나에게 넘깁니다.

### 요구 사항

- Windows 11 PC. 프로그램이 도는 동안 PC가 켜져 있어야 합니다(절전 해제 권장).
- 계정: 인스타그램(**프로 계정**이어야 인사이트를 읽습니다), 스레드, 네이버 블로그. 처음에는 계정 없이 드라이런으로 써볼 수 있습니다.
- API 키: Claude API(글 생성·답글), 이미지 생성 API(선택, 끄면 무료 템플릿만 사용), MotherDuck(분류, 무료 플랜).
- 브라우저: Aside 브라우저(기본) 또는 프로그램이 띄우는 Chromium 창에 직접 로그인.

### 위험 고지 (첫 실행 때 동의 화면이 나옵니다)

- 인스타그램·스레드·네이버·커뮤니티 약관은 자동화 도구 사용을 제한합니다. 계정이 제한되거나 정지될 수 있습니다. 이 도구는 빈도를 낮추고 무작위 간격을 두지만 위험을 없애지는 못합니다.
- 메인 계정 대신 **테스트 계정으로 먼저** 써 보고, 수집에는 수집 전용 계정을 쓰길 권합니다.
- 생성된 글은 AI가 쓴 것입니다. 설치 직후에는 **보호 모드**가 켜져 있어 첫 20건을 모두 내가 검토합니다. 품질을 확인한 뒤 대시보드에서 자동 게시를 켜세요.

### 법적 표기

이 도구는 모든 게시물에 다음을 자동으로 넣습니다. 끌 수 없습니다.
- 글 첫 줄: "AI를 기반으로 생성된 가상인물이 포함된 게시물입니다"
- 카드 이미지: "가상인물" 배지, AI 배경을 쓴 경우 "AI 생성 이미지"
- 협찬 게시물로 설정하면: "#광고"와 "광고" 배지

페르소나가 "직접 써 봤다"는 식의 체험 후기를 쓰는 것은 공정위 지침상 부당 광고가 될 수 있어 기본 금칙 패턴으로 막혀 있습니다. 실제 고객 후기는 자료로 올리면 출처와 함께 인용됩니다.

## 2. 설치와 첫 설정

### 설치

PowerShell에서 한 번만 실행합니다.

```powershell
winget install astral-sh.uv
uv python install 3.12
git clone https://github.com/idktomorrow/non-sleep-marketer.git
cd non-sleep-marketer
uv sync
uv run playwright install chromium
```

### 설정 마법사

```powershell
uv run nsm init
```

마법사는 다음 순서로 묻습니다. 다시 실행하면 기존 값이 기본값으로 나와서 엔터만 누르면 유지됩니다.

1. **위험 고지 동의**: 동의하지 않으면 설정이 저장되지 않습니다.
2. **브랜드**: 이름, 업종, 대표 제품, 핵심 메시지, 브랜드 색(카드뉴스 색이 됩니다).
3. **페르소나**: 활동 시간(예: `09:00-12:00, 18:00-23:00`, 자정을 넘는 `22:00-02:00`도 됩니다), 이름, 핸들, 인물상, 말투, 관심 주제, 금칙어, 협찬 표기 여부, 바로 켤지 여부. 체험 후기처럼 보이는 표현("써봤는데" 등)은 기본으로 막혀 있습니다.
4. **API 키**: Claude 키는 필수, OpenAI(배경 이미지)와 MotherDuck(분류)은 선택입니다. 키는 파일이 아니라 Windows 자격 증명 관리자에 저장됩니다. 입력할 때 화면에 보이지 않습니다.
5. **플랫폼**: 처음에는 "드라이런으로 시작"을 권합니다. 실제로 올리지 않고 미리보기 폴더에 결과만 저장합니다.

### 어디에 무엇이 저장되나

| 위치 | 내용 |
|---|---|
| `%USERPROFILE%\.nsm\config.yaml` | 브랜드·페르소나·운영 설정 (직접 고쳐도 됩니다) |
| `%USERPROFILE%\.nsm\data.duckdb` | 수집 자료, 콘텐츠, 댓글, 지표, 비용, 로그 |
| `%USERPROFILE%\.nsm\uploads\` | 내가 직접 올리는 자료(제품 정보, 보도자료, 엑셀, 고객 후기) |
| `%USERPROFILE%\.nsm\preview\` | 드라이런 결과물 |
| Windows 자격 증명 관리자 `non-sleep-marketer` | API 키 |

다른 위치를 쓰려면 환경 변수 `NSM_HOME`을 지정합니다.

### 점검

```powershell
uv run nsm doctor
```

`FAIL`이 없으면 시작할 수 있습니다. `WARN`은 선택 기능이 꺼져 있다는 뜻입니다.

### 주요 설정값 (config.yaml의 settings)

| 키 | 기본값 | 뜻 |
|---|---|---|
| `dry_run` | `true` | 실제 게시 대신 미리보기 저장 |
| `quotas` | 인스타 1, 스레드 2, 블로그 1 | 플랫폼별 하루 최대 게시 수 |
| `daily_cost_cap_usd` | `3.0` | 하루 API 비용 상한(달러). 넘으면 생성을 멈추고 알림 |
| `protect_count` | `20` | 보호 모드: 사람이 승인해야 하는 첫 콘텐츠 수 |
| `classifier` | `auto` | MotherDuck 토큰이 있으면 jev, 없으면 Claude로 분류 |
| `image_generation` | `auto` | OpenAI 키가 있으면 AI 배경, 없으면 템플릿 배경 |
