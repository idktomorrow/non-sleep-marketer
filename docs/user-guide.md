## 1. 시작 전에

### 무엇을 하는 도구인가

내 PC에서 계속 켜 두는 프로그램입니다. 내가 정한 "AI 가상 인플루언서" 페르소나가 자료를 모으고, 카드뉴스와 글을 만들어 인스타그램·스레드에 올리고, 내 게시물의 댓글에 답하고, 성과를 대시보드로 보여줍니다. 민감한 것(출처가 불확실한 글, 불만·환불·법적 댓글)은 자동 처리하지 않고 나에게 넘깁니다.

### 요구 사항

- Windows 11 PC. 프로그램이 도는 동안 PC가 켜져 있어야 합니다(절전 해제 권장).
- 계정: 인스타그램(**프로 계정**이어야 인사이트를 읽습니다), 스레드. 처음에는 계정 없이 드라이런으로 써볼 수 있습니다.
- API 키: Claude API(글 생성·답글), 이미지 생성 API(선택, 끄면 무료 템플릿만 사용), MotherDuck(분류, 무료 플랜).
- 브라우저: Aside 브라우저(기본) 또는 프로그램이 띄우는 Chromium 창에 직접 로그인.

### 위험 고지 (첫 실행 때 동의 화면이 나옵니다)

- 인스타그램·스레드·네이버·커뮤니티 약관은 자동화 도구 사용을 제한합니다. 계정이 제한되거나 정지될 수 있습니다. 이 도구는 빈도를 낮추고 무작위 간격을 두지만 위험을 없애지는 못합니다.
- 메인 계정 대신 **테스트 계정으로 먼저** 써 보고, 수집에는 수집 전용 계정을 쓰길 권합니다.
- 생성된 글은 AI가 쓴 것입니다. 설치 직후에는 **보호 모드**가 켜져 있어 첫 20건을 모두 내가 검토합니다. 품질을 확인한 뒤 대시보드에서 자동 게시를 켜세요.

### 법적 표기

이 도구는 모든 게시물에 다음을 자동으로 넣습니다. 끌 수 없습니다.
- 글 첫 줄: "AI를 기반으로 생성된 가상인물이 포함된 게시물입니다"
- 카드 이미지: "가상인물" 배지, AI 배경을 쓴 경우 "AI 생성 이미지"
- 협찬 게시물로 설정하면: "#광고"와 "광고" 배지

페르소나가 "직접 써 봤다"는 식의 체험 후기를 쓰는 것은 공정위 지침상 부당 광고가 될 수 있어 기본 금칙 패턴으로 막혀 있습니다. 실제 고객 후기는 자료로 올리면 출처와 함께 인용됩니다.

## 2. 설치와 첫 설정

### 설치

PowerShell에서 한 번만 실행합니다.

```powershell
winget install astral-sh.uv
uv python install 3.12
git clone https://github.com/idktomorrow/non-sleep-marketer.git
cd non-sleep-marketer
uv sync
uv run playwright install chromium
```

### 설정 마법사

```powershell
uv run nsm init
```

마법사는 다음 순서로 묻습니다. 다시 실행하면 기존 값이 기본값으로 나와서 엔터만 누르면 유지됩니다.

1. **위험 고지 동의**: 동의하지 않으면 설정이 저장되지 않습니다.
2. **브랜드**: 이름, 업종, 대표 제품, 핵심 메시지, 브랜드 색(카드뉴스 색이 됩니다).
3. **페르소나**: 활동 시간(예: `09:00-12:00, 18:00-23:00`, 자정을 넘는 `22:00-02:00`도 됩니다), 이름, 핸들, 인물상, 말투, 관심 주제, 금칙어, 협찬 표기 여부, 바로 켤지 여부. 체험 후기처럼 보이는 표현("써봤는데" 등)은 기본으로 막혀 있습니다.
4. **API 키**: Claude 키는 필수, OpenAI(배경 이미지)와 MotherDuck(분류)은 선택입니다. 키는 파일이 아니라 Windows 자격 증명 관리자에 저장됩니다. 입력할 때 화면에 보이지 않습니다.
5. **플랫폼**: 처음에는 "드라이런으로 시작"을 권합니다. 실제로 올리지 않고 미리보기 폴더에 결과만 저장합니다.

### 어디에 무엇이 저장되나

| 위치 | 내용 |
|---|---|
| `%USERPROFILE%\.nsm\config.yaml` | 브랜드·페르소나·운영 설정 (직접 고쳐도 됩니다) |
| `%USERPROFILE%\.nsm\data.duckdb` | 수집 자료, 콘텐츠, 댓글, 지표, 비용, 로그 |
| `%USERPROFILE%\.nsm\uploads\` | 내가 직접 올리는 자료(제품 정보, 보도자료, 엑셀, 고객 후기) |
| `%USERPROFILE%\.nsm\preview\` | 드라이런 결과물 |
| Windows 자격 증명 관리자 `non-sleep-marketer` | API 키 |

다른 위치를 쓰려면 환경 변수 `NSM_HOME`을 지정합니다.

### 점검

```powershell
uv run nsm doctor
```

`FAIL`이 없으면 시작할 수 있습니다. `WARN`은 선택 기능이 꺼져 있다는 뜻입니다.

### 주요 설정값 (config.yaml의 settings)

| 키 | 기본값 | 뜻 |
|---|---|---|
| `dry_run` | `true` | 실제 게시 대신 미리보기 저장 |
| `quotas` | 인스타 1, 스레드 2, 블로그 1 | 플랫폼별 하루 최대 게시 수 |
| `daily_cost_cap_usd` | `3.0` | 하루 API 비용 상한(달러). 넘으면 생성을 멈추고 알림 |
| `protect_count` | `20` | 보호 모드: 사람이 승인해야 하는 첫 콘텐츠 수 |
| `classifier` | `auto` | MotherDuck 토큰이 있으면 jev, 없으면 Claude로 분류 |
| `image_generation` | `auto` | OpenAI 키가 있으면 AI 배경, 없으면 템플릿 배경 |


## 3. 드라이런으로 결과 미리 보기

처음에는 실제 계정 없이 드라이런으로 돌려 봅니다(`config.yaml`의 `settings.dry_run: true`, 마법사 기본값).

```powershell
uv run nsm run
```

- 창에 `대시보드: http://127.0.0.1:8765`가 뜨면 브라우저로 엽니다. 이 주소는 내 PC에서만 열립니다.
- 프로그램은 정해진 시각에 알아서 움직입니다: 상태 점검 30분마다, 수집은 활동 시간 창 시작 20분 뒤(하루 2회), 생성은 첫 활동 시간 창 시작 50분 뒤, 게시는 30분마다(쿼터·간격 안에서), 댓글 확인 10분마다, 지표는 새벽 3시. 모든 시각에는 몇 분씩 무작위 지연이 섞입니다.
- 기다리지 않고 바로 보고 싶으면 대시보드 개요의 **지금 실행** 버튼(collect → generate → publish 순)을 누릅니다.
- 드라이런 게시물은 `%USERPROFILE%\.nsm\preview\날짜\콘텐츠ID\플랫폼\`에 카드 PNG(1080×1350, 브랜드 색과 Pretendard 글꼴)와 원고로 저장되고, 20분 간격으로 가짜 댓글이 달려 대댓글 흐름까지 확인할 수 있습니다.
- 끄려면 창에서 `Ctrl+C`.

한 번만 돌려 보고 싶을 때(디버그):

```powershell
uv run nsm run --once --job collect
uv run nsm run --once --job generate
uv run nsm run --once --job publish
```

카드 디자인만 확인하고 싶으면 덱 JSON 하나를 바로 그려 볼 수 있습니다(예시 덱: `tests/fixtures/decks/`).

```powershell
uv run nsm render-preview tests/fixtures/decks/info.json --out preview-cards
```

`nsm run`이 켜져 있는 동안에는 `--once`를 쓸 수 없습니다(데이터 파일을 한 프로세스만 열 수 있음). 대시보드의 **지금 실행**을 쓰세요.

## 4. 대시보드 사용법

| 화면 | 할 수 있는 일 |
|---|---|
| 개요 | 페르소나 켜기/끄기, 자동 게시 켜기/끄기, 검토 대기·확인할 댓글·오늘 게시·오늘 비용 보기, 잡 지금 실행, 최근 실행 결과 |
| 검토 대기열 | 자동 게시되지 않은 콘텐츠와 그 사유. 승인 또는 폐기 |
| 검토 상세 | 카드 원고, 사실 주장과 출처, 금칙어 경고, 플랫폼별 게시 상태. 캡션·스레드 글·블로그 제목과 본문·표지 제목 고치기 |
| 댓글 | 사람이 확인할 댓글(불만, 가격·환불, 법적 문제, 스팸 추정, 분류 불확실, 답글 초안에 금칙어). 직접 답글 보내기 또는 처리 완료 |
| 성과 | 게시물별 조회·도달·좋아요·댓글·저장·공유, 팔로워, 댓글 처리 현황(평균 자동 응답 시간), 최근 14일 비용 |
| 실행 로그 | 잡별 실행 시각과 결과 요약, 오류 |

자주 하는 일:

1. **처음 20건 검토하기**: 자동 게시를 켜도 보호 모드라 처음 20건은 검토 대기열로 옵니다. 하나씩 열어 출처와 문구를 확인하고 승인하세요. 20건을 승인하면 기준을 통과한 콘텐츠는 자동으로 올라갑니다.
2. **실패했던 게시 다시 시도**: 게시가 4번 실패하거나 중간에 끊긴 콘텐츠는 검토 대기열로 돌아옵니다. 플랫폼에서 실제로 안 올라간 것을 확인한 뒤 승인하면 처음부터 다시 시도합니다.
3. **댓글 처리**: 알림이 오면 댓글 화면에서 직접 답하거나, 답할 필요가 없으면 처리 완료를 누릅니다.


## 6. 성과와 주간 리포트 읽는 법

### 성과 화면

- **게시물별 지표**: 조회·도달·노출·좋아요·댓글·저장·공유. 플랫폼마다 제공하는 지표가 다릅니다(블로그는 저장·공유 없음, 인스타 도달·노출은 프로 계정 필요). 없으면 `-`.
- **팔로워**: 하루 한 번(새벽) 기록합니다.
- **댓글 처리**: 자동 답글·숨김·사람 확인 건수와 평균 자동 응답 시간.
- **비용**: 최근 14일, 종류별(글 생성 llm, 이미지 image, 분류 classifier).

### 주간 리포트

매주 월요일 오전 8시에 지난주(어제까지 7일, 현지 날짜 기준) 결산이 `%USERPROFILE%\.nsm\reports\weekly-날짜.md`로 만들어지고 알림이 옵니다. 대시보드 **주간 리포트** 화면에서도 볼 수 있고, 개요의 지금 실행에서 `weekly_report`로 바로 만들 수도 있습니다.

| 절 | 내용 |
|---|---|
| 요약 | 플랫폼별 게시 수, 평균 참여율, 댓글 처리, 비용 합계 |
| 팔로워 | 플랫폼별 주초 → 주말 변화 |
| 가장 잘된 콘텐츠 | 참여율 상위 3개와 이유(평균 대비 배수, 형식, 게시 시간대, 주제, 저장이 많은지) |
| 다음 주 추천 주제 | 내 관심 주제 중 참여율이 높았고 쓸 자료가 남은 순서, 관련 급상승 검색어 |
| 협찬(광고) 게시물 | 광고 표기 게시물만 따로(미디어킷용) |

**참여율** = (좋아요 + 댓글 + 저장 + 공유) ÷ 조회. 아직 성과 기록이 없는 주제는 평균보다 조금 낮게 쳐서, 검증된 주제가 먼저 추천됩니다. 리포트는 정해진 계산 규칙으로 만들어서 API 비용이 들지 않고, 같은 데이터면 늘 같은 결과가 나옵니다.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 무엇이든 이상할 때 | `uv run nsm doctor`로 Python, 데이터, 설정, API 키, 브라우저, 폰트를 점검 |
| API 키가 진짜 되는지 | `uv run nsm doctor --live`: Claude·MotherDuck을 한 번씩 실제로 호출(비용 1원 미만). `--with-image`를 붙이면 OpenAI 이미지도 1장(약 70원) |
| 생성이 안 됨 | 실행 로그에 "Claude API 키가 없어" → `nsm init`으로 키 입력. "비용 상한" → 오늘 비용이 상한에 닿음(다음 날 재개, 또는 `daily_cost_cap_usd` 조정). "쓸 자료 없음" → 관련 자료가 모일 때까지 기다리거나 `uploads` 폴더에 자료 추가 |
| 게시가 안 됨 | 페르소나가 꺼져 있거나 활동 시간 밖, 오늘 쿼터를 채움, 같은 플랫폼 직전 게시 후 3시간이 안 됨, 콘텐츠가 승인되지 않음 중 하나 |
| "로그인 필요" 알림 | 그 플랫폼의 자동 게시·답글이 멈춘 상태. 브라우저에서 다시 로그인하면 다음 상태 점검(30분 이내)에 자동으로 다시 시작 |
| `--once`가 "파일을 열 수 없음"으로 실패 | `nsm run`이 이미 켜져 있음. 대시보드의 지금 실행을 쓰기 |
| PC를 켤 때 자동으로 실행되게 | `uv run nsm install-autostart` (해제: `nsm uninstall-autostart`). 로그는 `%USERPROFILE%\.nsm\logs\` |

## 8. 표기 의무와 콘텐츠 정책

### 자동으로 붙는 표기 (끌 수 없음)

| 어디에 | 무엇이 |
|---|---|
| 인스타그램 캡션·스레드 글·블로그 본문의 첫 줄 | `AI를 기반으로 생성된 가상인물이 포함된 게시물입니다` |
| 블로그 제목 끝 | ` [가상인물 포함]` |
| 카드 이미지 모든 장 | "가상인물" 배지 |
| AI 배경을 쓴 카드 | "AI 생성 이미지" 작은 캡션 |
| 협찬 표기를 켠 경우 | 첫 줄 맨 앞에 `#광고`, 표지 카드에 "광고" 배지 |

협찬 여부는 설정 마법사의 "협찬(광고) 게시물로 표기할까요?"나 config.yaml의 `persona.ad_label`로 정합니다.

### 무엇이 자동 게시되고 무엇이 검토로 가나

아래 중 하나라도 해당하면 자동으로 올리지 않고 대시보드의 검토 대기열로 갑니다. 대기열에서는 사유가 함께 보입니다.

1. **자동 게시가 꺼져 있음**: 설치 직후 기본값입니다.
2. **보호 모드**: 자동 게시를 켜도 내가 직접 승인한 콘텐츠가 20건이 될 때까지는 모두 검토합니다.
3. **출처가 확인되지 않는 주장**: 글의 사실 주장마다 근거 자료가 연결돼야 합니다. 이번에 쓴 자료가 아닌 것을 근거로 대면 검토로 갑니다.
4. **관련성 부족**: 실제로 인용한 자료의 관련성이 0.8 미만.
5. **금칙어·금칙 패턴**: 내가 정한 금칙어, 그리고 "써봤는데", "내돈내산" 같은 가상인물의 체험 표현.

### 게시 규칙

- 활동 시간 안에서만, 플랫폼별 하루 쿼터(기본 인스타 1, 스레드 2, 블로그 1) 안에서만 올립니다.
- 같은 플랫폼에 연달아 올리지 않도록 최소 3시간 간격을 둡니다(`min_hours_between_posts`).
- 게시에 실패하면 15분, 1시간, 4시간 뒤 다시 시도하고, 그래도 실패하면 알림을 보내고 검토 대기열로 돌립니다.
- 게시 도중 PC가 꺼지거나 프로그램이 죽으면, 실제로 올라갔는지 알 수 없으므로 자동으로 다시 올리지 않습니다. 검토 대기열에 "중단됨, 플랫폼 확인 필요"로 표시되니 플랫폼에서 확인한 뒤 다시 승인하세요.

### 드라이런 결과 보기
