# 배치 devlog

배치 하나가 끝날 때마다 한 파일. 프로젝트가 시간순으로 어떻게 흘러갔는지, 무엇이 막혔고 어떻게 풀었는지, 그 과정에서 배운 개념을 남깁니다. 파일명 `YYYY-MM-DD-batch-<id>.md`.

## 템플릿

```markdown
# 배치 <id>: <제목> (YYYY-MM-DD)

- 이슈: #, # · PR: # · 브랜치: batch/<id>-<slug>
- 소요: 시작 HH:MM → PR HH:MM

## 목표
이 배치가 끝나면 무엇이 가능해지는가 (process.md 표의 "끝났을 때 보이는 것").

## 한 일
- 모듈/파일 단위로 3~8줄. 무엇을 만들었고 어디에 있는가.

## 막힌 것과 해결
- 증상 → 원인 → 해결. 없으면 "없음".

## 배치 중 내린 결정
- ADR 링크(상태 `제안`). 없으면 "없음".

## 테스트 결과
`uv run pytest` 요약 줄(통과/실패/스킵 수)과 새로 추가한 테스트 목록.

## 배운 것 (신입 개발자용)
1. **개념 이름**: 이 배치에서 어디에 쓰였는지 + 왜 필요한지 3~5문장.
2.
3.

## 다음 배치 메모
다음 세션이 알아야 할 것(남긴 TODO, 주의점).
```
