# 배치 M16: 마케터용 카드 편집 화면 (2026-10-13)

- 이슈: #35 · 브랜치: batch/M16-card-editor · 담당: 메인(Claude)

## 목표

검토 상세 화면(`/review/{id}`)에서 마케터가 카드를 직접 다듬는다. 대상은 슬라이드별 문구, 배경 이미지, 그리고 게시 전 미리보기다. 화면 모양은 배치 I에서 바꾸고, 여기서는 라우트와 동작을 만든다.

## 한 일

- `nsm/app/card_editor.py`(순수 함수):
  - 폼 → 덱 반영(`apply_slide_edits`, 계약 검증 실패는 `EditError`)
  - 업로드 판정·저장(`sniff_image`, `save_upload`)
  - 배경 교체와 AI 표기 재계산(`set_background`)
  - 렌더 결과 지우기(`clear_rendered`)
- `nsm/app/server.py`:
  - `POST /review/{id}/edit`: 슬라이드별 칸 `s{번호}_{칸}`. 예전 `cover_title` 폼과 호환하고, 폼에 없는 칸은 그대로 둔다.
  - `POST /review/{id}/slides/{n}/background`(올리기·바꾸기), `.../background/remove`(지우기)
  - `POST /review/{id}/preview`: 지금 원고로 미리보기를 렌더한다. 잡 스레드에서 그리고 넘침을 기록한다.
  - `GET /previews/{id}/{name}`: id는 DB에 있는 것만 받는다.
  - `AppState.renderer`: 런타임이 잡 컨텍스트의 렌더러를 넘긴다.
- `review_detail.html`: 슬라이드마다 입력 칸, 배경 올리기·지우기, 미리보기 영역과 넘침 경고. 출처는 읽기 전용이다.
- 스타일 선택은 S8(#34) 뒤로 미뤘다(ADR 0024).

## 막힌 것과 해결

- **덱 계약 검증**: `model_copy(update=...)`는 검증을 하지 않는다. 사람이 목록을 비우면 계약에 어긋난 덱이 저장될 수 있었다. 칸마다 `model_validate`로 다시 만들고, 실패하면 "2장 bullets: …"처럼 위치를 알려 주는 400을 돌려준다.
- **AI 표기는 덱에 하나**: 사진을 올린 장에도 "AI 생성 이미지"가 붙거나, 반대로 AI 배경이 남았는데 표기가 꺼질 수 있었다. 배경 경로로 생성기 이미지인지 판정해, AI 배경이 하나라도 남아 있으면 켠다. 표기가 빠지는 쪽을 막았다.
- **미리보기와 게시 렌더 충돌**: 렌더러의 `last_overflow`는 공유 값이라, 대시보드 스레드에서 그리면 게시 잡의 넘침 판정과 섞일 수 있다. 미리보기도 잡 스레드(`submit`)에서 그린다.

## 배운 것 (신입 개발자용)

1. **사용자 업로드는 내용으로 판정한다**: 파일 이름이나 브라우저가 보낸 Content-Type은 사용자가 마음대로 바꿀 수 있다. 앞 몇 바이트(매직 넘버: PNG는 `\x89PNG`)로 형식을 정하고, 저장 이름도 서버가 만든다. 그래야 `../../evil.png` 같은 이름으로 다른 폴더에 쓰는 공격(경로 탐색)이 통하지 않는다.
2. **복사와 검증은 다르다**: pydantic의 `model_copy(update=...)`는 빠르지만 검증을 건너뛴다. 사람이 입력한 값처럼 믿을 수 없는 값이 들어갈 때는 `model_validate`로 다시 만들어야 계약이 지켜진다.
3. **캐시는 입력이 바뀌면 버린다**: 게시용 카드 PNG는 원고의 렌더 결과(캐시)다. 원고나 배경을 바꾸고 캐시를 지우지 않으면 고치기 전 카드가 올라간다. 바꾸는 모든 길(문구, 배경 올리기, 배경 지우기)에서 같은 함수(`clear_rendered`)로 지운다.

## 코드 리뷰 반영

- **[높음] 미리보기 넘침 경고가 거짓으로 "없음"**: 잡 실행기는 작업자가 하나라, 긴 잡이 돌면 미리보기 요청이 90초 뒤 504로 끝났다. 그 뒤에 렌더가 늦게 실행되면 넘침 기록 없이 PNG만 남았고, 화면은 "넘치는 장 없음"을 띄웠다. 그 사이 고친 원고 대신 옛 원고로 그린 미리보기가 다시 생길 수도 있었다. 고친 내용:
  - 렌더 함수 안에서 실행 시점의 원고를 다시 읽는다.
  - 넘침 기록을 PNG와 함께 쓰고, 실패하면 정리한다.
  - 넘침 기록이 없는 미리보기는 보여 주지 않는다.
- **[낮음] 빈 필수 문구 저장**: 덱 모델이 빈 문자열을 허용해 빈 표지가 게시될 수 있었다. 편집기에서 제목·소제목·본문·마무리·비교 양쪽을 비우지 못하게 막는다.
- **[낮음] 업로드 파일이 쌓임**: 배경을 바꾸거나 지우면 예전 업로드 파일(업로드 폴더 안의 것만)을 지운다.
- **[낮음] 테스트가 주장한 것을 검증하지 않음**: 경로 테스트에 핸들러까지 가는 값을 넣었고, 크기 제한은 라우트에서 검사한다.
