# 2026-11-18 배치 C50: "백업 복사 폴더"를 Windows 폴더 선택 창으로 고르기

## 목표

C49의 "백업 복사 폴더" 칸 옆에 "폴더 고르기…" 버튼을 두어, 경로를 손으로 옮겨 적지 않고 Windows 폴더 선택 창에서 고르게 한다.

## 한 일

1. **`nsm/app/folder_picker.py`(새 파일)**: `pick_folder(title, initial, timeout_s=300, runner=None) -> str | None`.
   - PowerShell `-STA -NoProfile -NonInteractive -EncodedCommand`로 `FolderBrowserDialog`를 띄운다. `Description`=제목,
     `SelectedPath`=처음 폴더(있으면), `ShowNewFolderButton` 켬, 맨 위에 뜨는 폼을 주인으로 `ShowDialog($o)`.
     출력은 `[Console]::OutputEncoding = UTF8`. OK면 경로 한 줄, 취소면 출력 없음.
   - 실행기 주입(`runner`). 진짜 실행기 `powershell_runner`는 Windows 아님·PowerShell 없음·시간 초과·0이 아닌 종료 코드를
     `PickerUnavailable`로. 주입한 실행기가 무슨 예외를 내도 `PickerUnavailable` 하나로 바꾼다.
   - 모듈 잠금(`threading.Lock`, `acquire(blocking=False)`): 잡혀 있으면 기다리지 않고 `PickerBusy`.
   - `ps_literal`: 작은따옴표 리터럴. `'` 말고도 PowerShell이 따옴표로 보는 `‘’‚‛`를 두 번 쓴다. NUL은 뺀다.
2. **라우트 `POST /settings/pick-folder`**(CSRF): 폼 `initial`(지금 칸 값, `clean_path`)을 넘겨 부르고
   `{"path"}`·`{"cancelled": true}`·`{"error": 문구}`(바쁨이면 `"busy": true`도)를 돌려준다. `def` 라우트라
   스레드 풀에서 돌아 잡 큐를 막지 않는다. 문구는 `ko.FOLDER_PICKER`.
3. **화면**: 칸 옆 `type=button` "폴더 고르기…"와 안내 줄(`role=status`). `nsm/app/static/settings.js`(새 파일)가
   누르면 버튼을 잠그고 "선택 창이 떴습니다…", 경로가 오면 칸을 채우고 "저장을 눌러야 반영됩니다"(떠날 때 경고가
   뜨게 `input` 이벤트도 보냄), 취소면 원래 안내로, 오류면 문구를 빨갛게. 인라인 스크립트는 더하지 않았다.
4. **placeholder**: 서버가 `Path.home() / "OneDrive" / "nsm-backups"`로 만들어 넘긴다. placeholder라 폼에 실리지 않아 저장되지 않는다.
5. **데모**: `scripts/dashboard_demo.py`에 가짜 실행기(`_demo_pick_folder`)를 넣어, 데모에서 버튼을 눌러도 진짜 창이 뜨지 않는다.
6. 문서: ADR 0075(채택), architecture 갱신 줄·상태 표, CHANGELOG, user-guide 7절. 버전 0.4.42.

## 막힌 것과 해결

- **셸의 `python`이 Microsoft Store 안내 껍데기**: 여러 파일을 한 번에 고치는 스크립트를 `python -`로 돌렸더니 "Python"만
  찍고 아무것도 안 했다. `git status`로 안 바뀐 것을 확인하고 Edit로 다시 했다. 파이썬은 늘 `uv run python`으로.
- **따옴표 안전을 진짜 PowerShell 없이 확인**: 테스트는 인코딩된 명령을 풀어 문자열을 비교한다. 따로 한 번 PowerShell
  파서(`Parser.ParseFile`, 실행 안 함)로 `'`·`’`·`$(calc)`가 든 값을 넣은 스크립트를 읽혀, 문법 오류 0·하위 식 0이고
  작은따옴표 문자열 값이 넣은 값과 똑같음을 확인했다.
- **스크린샷**: 예시 데이터 데모 서버(전: 메인 폴더 코드 8798, 후: 워크트리 8797)만 찍었다. 운영 대시보드는 찍지 않았다.
  데스크톱·모바일(390px) 모두 가로 넘침 없음.

## `/code-review` 반영

고친 것:
- 창을 띄우다 실패해도(대화형 세션이 아님 등) PowerShell이 0으로 끝나 "취소"로 보였다: `$ErrorActionPreference='Stop'`·try/catch로 종료 코드 1, "열 수 없음" 안내와 WARNING.
- 창이 떠 있는 동안 Ctrl+C를 누르면 요청 스레드가 최대 5분 종료를 붙잡았다: 실행기를 `Popen`으로 바꿔 지금 프로세스를 기억하고, `runtime`의 Ctrl+C 처리에서 `cancel_picker()`로 닫는다.
- 알림(`toast_script`)은 `'`만 두 번 써서, 뉴스 제목의 굽은 따옴표(‘’)가 리터럴을 끝낼 수 있었다: `ps_literal`을 `nsm/adapters/notify/windows.py`로 옮겨 알림과 선택 창이 같이 쓴다.
- 시간 초과도 "열 수 없음"이었다: `PickerTimeout`과 "5분 동안 고르지 않아 선택 창을 닫았습니다. 다시 누르세요".
- `nsm run`을 다시 켠 뒤 낡은 화면에서 누르면(403) "열 수 없음"이 떴다: "화면이 오래됐습니다. 새로고침한 뒤 다시 누르세요".
- 내 PC·라이브러리처럼 실제 폴더가 아닌 곳에서 OK를 누르면 빈 경로라 "취소"로 보였다: 종료 코드 3 → `PickerNotFolder`와 안내.
- 출력에 BOM이 붙을 가능성: BOM 없는 `UTF8Encoding $false`로 쓰고, 읽을 때 `utf-8-sig`·`﻿`도 뗀다.
- ADR의 "알림과 같은 방식" 문장이 `-STA`·따옴표 처리 차이를 숨겼다: 차이를 적었다.

그대로 둔 것:
- ADR 상태 "채택": 요청이 상태를 정했다.

## 배운 것 3개

1. **브라우저는 폴더의 전체 경로를 주지 않는다**: 웹 페이지가 사용자 디스크 구조를 알면 안 되기 때문이다. 우리 대시보드는
   같은 PC의 127.0.0.1에서만 열리므로, 서버가 직접 Windows 창을 띄우는 쪽이 오히려 맞다. 원격에서 여는 구조였다면 창이
   엉뚱한 PC(서버)에 뜨니 쓸 수 없는 방법이다. 같은 기능도 "누가 어디서 쓰나"에 따라 답이 달라진다.
2. **사용자 값을 다른 언어의 코드에 넣을 때는 그 언어의 규칙을 다 알아야 한다**: PowerShell 작은따옴표 문자열은 `'`를
   두 번 쓰면 된다고 알려져 있지만, PowerShell은 `‘’`(굽은 따옴표)도 같은 따옴표로 본다. 하나라도 빠지면 경로 이름으로
   코드를 넣을 수 있다. 그래서 값은 문자열 리터럴 안에만 두고, 실행 전 파서로 "값이 문자열 하나로 읽히는지"를 확인했다.
3. **오래 기다리는 일은 어느 스레드에서 도는지 먼저 정한다**: 선택 창은 사람이 고를 때까지 몇 분도 기다린다. 이것을 잡
   큐(작업 스레드 하나)에 넣으면 그동안 게시·수집이 멈춘다. FastAPI의 `def` 라우트는 스레드 풀에서 돌아 다른 요청과 잡을
   막지 않는다. 대신 동시에 두 창이 뜨지 않게 잠금을 두고, 잡혀 있으면 기다리지 않고 바로 "이미 떠 있음"을 돌려준다.

## 다음 배치 메모

- 선택 창이 브라우저 뒤에 뜨는지는 Windows 포커스 규칙에 달려 있다. 맨 위 폼을 주인으로 넘겼지만, 실제로 뒤에 숨는 일이
  있으면 안내("작업 표시줄을 확인하세요")가 받친다. 사용자 보고가 오면 `SetForegroundWindow`를 본다.
- 다른 경로 칸(자료 폴더 등)이 생기면 같은 라우트에 `title`만 바꿔 쓸 수 있게 일반화를 본다.
