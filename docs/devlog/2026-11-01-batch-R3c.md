# 2026-11-01 배치 R3c: 문서 질문 손질

## 목표

문서 질문 탭(R3)을 실제로 써 보고 나온 손질거리를 한 번에 고친다. 검색·답변 규칙(기준값 0.65, 조각 안에서만 답함, 두 겹 "모른다")은 그대로다.

## 한 일

- **새로고침 중복 전송 막기**: POST /ask는 질문을 처리해 `doc_qa`에 저장한 뒤 303으로 `/ask?qa=<기록 id>#answer`에 보낸다. GET이 저장된 기록(답·근거·비용·시간)을 보여 준다. 거절은 그 자리에 400.
- **근거 본문 저장**: `doc_qa.sources`에 조각 본문도 넣는다. 이전 기록은 "원문 없음".
- **최근 질문 기록**: 행의 질문을 누르면 그 기록, 행마다 "지우기", 목록 위 "전부 지우기"(확인 창 + 서버에서 `confirm=yes` 확인). 모두 CSRF.
- **보관**: 유지보수 잡이 `run_log_keep_days`가 지난 질문 기록을 지운다(`qa_pruned`, 실행 기록 문장). `doc_eval`은 남긴다.
- **표시**(`nsm/app/ask_format.py`)
  - 시간은 "2.1초"로 보인다.
  - 비용은 "$0.0003 (약 0.5원)"으로 보인다(`settings.krw_per_usd` 1,400).
  - 답 글은 전부 이스케이프한 뒤 백틱 한 쌍만 `<code>`로 바꾼다.
  - [n]은 근거 목록에 있는 번호만 `#src-n` 링크로 바꾼다.
- **입력 동작**(`nsm/app/static/ask.js`, JS 없이도 폼은 동작)
  - 묻기·측정 버튼을 누르면 잠그고 "찾는 중…"/"재는 중…"을 보인다.
  - [n]을 누르면 그 근거를 펼치고 그리로 간다.
- **측정 안내**: 주소창에는 코드(`ok`, `limit`, `no_key`, `cost_cap`, `no_file`, `stopped`, `error`)만 넘긴다. 문구는 서버가 고르고, 모르는 코드는 무시한다.
- ADR 0058 개정 1, 설명서 문서 질문 절 두 줄, architecture, CHANGELOG. 버전 0.4.18.

## 막힌 것과 해결

- **본문을 저장할까, 조각 id로 다시 읽을까.** 조각은 문서가 바뀌면 색인이 지우고 다시 만들어 id·본문이 바뀐다. id로 다시 읽으면 "답할 때 본 근거"가 아니게 된다. 조각당 수백 자라 저장 쪽을 골랐다.
- **버튼을 잠그면 폼이 안 간다.** 제출 이벤트 안에서 바로 `disabled`를 걸면 브라우저가 그 버튼의 제출을 취소한다. `setTimeout(…, 0)`으로 제출이 시작된 뒤에 잠갔다.
- **"전부 지우기"의 확인 한 번 더.** JS 확인 창만 믿으면 JS 없이 누를 때 바로 지워진다. 확인 창을 거친 폼만 `confirm=yes`를 채우고, 서버는 이 값이 없으면 지우지 않는다.
- **기존 R3 테스트가 예전 화면을 전제했다**(측정 안내 문구가 주소창에, 최근 질문 제목 모양, 유지보수 결과 키). 코드·새 제목·`qa_pruned`에 맞췄다.
- **테스트 기대값 계산 실수.** 가짜 사용량(입력 2,000·출력 200토큰, haiku)은 $0.0003이라 1,000원 환율이면 0.3원이다. 처음에 0.5원으로 적었다.

## 배운 것 (신입 개발자용)

1. **POST 뒤에는 리다이렉트.** POST 결과를 그 자리에서 그리면 새로고침이 POST를 다시 보낸다. 저장하고 GET 주소로 보내면(PRG 패턴) 새로고침은 그냥 다시 읽기다. 돈이 드는 요청일수록 꼭 필요하다.
2. **안전한 HTML은 "다 막고 몇 개만 연다".** 모델 답을 마크다운으로 렌더링하면 이스케이프가 어디서 풀리는지 따라가기 어렵다. 전부 이스케이프한 뒤 우리가 아는 모양(백틱 한 쌍, [숫자])만 우리가 만든 태그로 바꾸면, 들어갈 수 있는 HTML이 정해진다.
3. **주소창에는 문구 대신 코드.** 안내 문구를 주소에 실으면 누구나 그 주소로 아무 글이나 화면에 띄울 수 있다. 코드만 넘기고 서버가 아는 코드만 문구로 바꾸면 그 길이 막힌다.
