# 2026-10-23 배치 C31: 원고 품질 하한 — 빈약한 자료·같은 소식·소재 쏠림 거르기

## 목표

"달력 어디서 살까요? → 검색해 보세요" 같은 빈 원고와, 극장판 흥행 소식이 9번 올라가는 중복을 막는다. 사용자 결정: 1~8번 수정 전부(ADR 0051), 관심 주제 재정비는 설정에서.

## 한 일

- `nsm/engine/material.py`(신규): 재료 고르기를 generate에서 떼어 냄. 본문 최소 길이, 구체 사실 'none' 제외, 같은 사건 1차(제목 낱말 겹침)·2차(분류기 same_news) 제외 + `duplicate_event` 표시, 주제 주간 상한.
- `collect.py`: 원문 읽기 상한을 설정값(24)으로, 원문 읽기가 끝난 관련 자료에 구체 사실 판정(`facts` 열, 스키마 v4).
- `generate.py`: 비교형은 자료 둘 이상일 때만, 구체 사실 수(`fact_count`)가 하한 미만이면 검토로.
- `quality.py`: `FILLER_PHRASES`(규칙 위반 → 재생성), `fact_count`, `title_tokens`·`same_event`.
- 생성 지시에 "자료가 부족하면 일반론으로 채우지 말 것" 추가. 설정 4개(`min_source_chars`·`min_facts`·`topic_weekly_limit`·`max_bodies_per_run`).
- ADR 0051, 설명서 설정표·품질 규칙 절, known-gaps 2-4, CHANGELOG. 버전 0.4.6.

## 막힌 것과 해결

- **구체 사실 판정을 언제 하나.** 원문을 받기 전에 판정하면 요약문 기준이라 다 'none'이 된다. 원문 읽기가 끝난 자료만(가져옴·건너뜀·재시도 소진, 또는 소스에 읽기 기능이 없음) 판정하도록 collect 끝에 붙였다.
- **같은 사건 판정의 과잉.** 처음엔 낱말이 적으면 포함 관계로 봤더니 "원두 소식"이 "원두: 지난 글"의 부분집합이라 전부 중복이 됐다. 낱말 두 개 이하는 완전 일치만, 셋 이상은 자카드 0.5.
- **기존 테스트의 자료가 짧다**(22~52자). 하한을 기본값으로 두면 전부 "쓸 자료 없음"이 된다 → 테스트 페르소나 픽스처에서 하한을 0으로 두고, 하한은 전용 테스트에서만 켠다.
- **마이그레이션 멱등성.** v1 DB 테스트가 새 스키마로 만든 뒤 버전만 1로 되돌려 4번 마이그레이션이 이미 있는 열을 또 추가하려 했다 → `ADD COLUMN IF NOT EXISTS`.

- **코드 리뷰 지적 10건(모두 반영)**: ① 낱말 대체 분류기가 facts 라벨을 몰라 전부 'no_facts'로 찍어 재료 0건이 되던 것 → keyword일 땐 판정 안 함. ② 브라우저 없는 실행에서 요약문으로 판정해 굳히던 것 → 본문 결론 난 자료만 판정, 본문을 받으면 재판정. ③ 최근 제목을 가나다순 20개만 보내던 것 → 최신순. ④ 주제 낱말('치이카와')이 도메인에 하드코딩 → 페르소나 주제에서 만든 stop 집합. ⑤ 한글 뒤 낱말 경계 때문에 '다이소에서'가 안 잡히던 것 → 경계 제거. ⑥ '1.'·날짜를 셋으로 세던 것 → 날짜 먼저 떼고 한 자리 숫자 제외. ⑦ 대시보드 "쓸 수 있는 자료" 수가 재료 조건과 달랐던 것 → 같은 조건(`USABLE_SOURCE`). ⑧ 같은 소식 판정을 한 건씩·매번 묻던 것 → 주제당 10건 묶음 + 판정 기록. ⑨ 일괄 판정 실패 시 대체 경로 없음 → 한 건씩 재시도. ⑩ 죽은 상수 `MAX_BODIES_PER_RUN` 제거. 보조: "확인해 보세요"·"참고하세요"는 정상 마무리에도 흔해 일반론 목록에서 뺌.

## 배운 것 (신입 개발자용)

1. **빈 글은 모델이 아니라 재료 문제다.** "자료에 없는 사실은 쓰지 마라"는 좋은 규칙이지만 자료가 비면 모델은 규칙을 지키면서 일반론으로 칸을 채운다. 품질의 하한은 생성 단계가 아니라 재료 단계에서 정해진다.
2. **중복은 URL이 아니라 사건 단위로 본다.** 같은 보도자료를 열 매체가 쓰면 URL은 열 개다. "같은 사건인가"는 제목 낱말 겹침으로 거칠게, 분류기로 정밀하게, 두 겹으로 본다.
3. **포함 관계는 작은 집합에서 거짓말을 한다.** 낱말 하나짜리 제목은 어디에든 포함된다. 집합 비교 규칙을 만들 땐 크기가 작을 때의 경계 조건을 따로 정한다.
