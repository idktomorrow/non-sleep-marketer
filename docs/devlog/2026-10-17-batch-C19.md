# 2026-10-17 배치 C19: 캐릭터 "AI 생성 이미지" 표기 기본 끔

## 목표

C17에서는 기본 캐릭터(앵무새·햄스터)를 만든 방법을 몰랐다. 그래서 캐릭터가 있는 장에 "AI 생성 이미지"를 붙이는 쪽을 기본으로 두었다.

선웅제가 확인해 준 사실과 결정은 이렇다.
- 팀원이 AI로 만든 그림이다.
- 그래도 표기는 붙이지 않는다.

## 한 일

- 설정 `brand.character_ai_made`의 기본값을 `False`로 바꿨다.
- 설정 화면 체크 칸의 문구를 바꿨다.
  - 예전: "이 그림은 AI로 만들었어요"
  - 지금: "캐릭터가 있는 장에 'AI 생성 이미지' 표기하기"
  - 실제처럼 보이는 그림을 올리면 켜라는 안내를 붙였다.
- ADR 0046에 결정과 근거를 적었다. 사용설명서, architecture, CHANGELOG도 고쳤다.

## 막힌 것과 해결

- **"저작권이 없으니 안 붙여도 된다"는 근거가 맞나.**
  - 표기는 저작권 문제가 아니라 투명성 문제다. 그래서 근거를 따로 찾았다.
  - AI 기본법 제31조의 표시 의무는 AI 제품·서비스를 제공하는 인공지능사업자가 진다. 엄격한 표시가 필요한 것은 실제와 구분하기 어려운 결과물(딥페이크)이다.
  - Meta가 이용자에게 직접 밝히라고 요구하는 것도 사실적인 AI 영상·음성이다.
  - 만화 마스코트는 둘 다에 해당하지 않는다고 보고 결정을 기록했다. 다시 볼 조건(가이드라인 변경, 변호사 확인)도 함께 남겼다.

## 테스트 결과

- `uv run ruff check .`, `uv run ruff format --check .` 통과
- `uv run pytest`: 751 passed, 13 deselected
  - 실행 중인 `nsm run` 때문에 `--no-sync`로 돌렸다.
- `tests/render/test_character.py`: 기본은 표기 없음, 켜면 표기

## 배운 것 (신입 개발자용)

1. **기본값은 결정이다.** 모를 때는 안전한 쪽(표기 켬)으로 두고, 사실이 확인되면 사람의 결정에 맞춰 바꾼다. 바꾼 이유는 ADR에 남겨, 나중에 "왜 꺼져 있지?"에 답할 수 있게 한다.
2. **비슷해 보이는 규칙을 섞지 않는다.** 저작권(누가 권리를 갖나), AI 표시(AI가 만들었다고 알리나), 가상인물 표기(광고 심사지침)는 서로 다른 규칙이다. 하나를 근거로 다른 하나를 정하면 틀리기 쉽다.
3. **체크 칸 문구는 "결과"를 말하게.** "AI로 만들었어요"는 사실을 묻는 것처럼 읽힌다. "표기하기"는 무엇이 바뀌는지를 말한다. 사람은 결과를 보고 고른다.
