## 배운 것 3개
1. "원자적 교체"는 속성 하나씩 바꾸는 게 아니라 **묶음을 새로 만들고 잡은 스냅샷을 쓰는 것**이다. 그래야 실행 중인 잡이 반쯤 바뀐 상태를 보지 않는다.
2. 외부 API 오류는 "재시도할까"보다 **"요청이 서버에 닿았나"**를 먼저 가른다. 닿은 뒤 응답을 못 받은 유료 이미지 요청은 다시 보내면 두 번 과금될 수 있어 미확인으로 남긴다.
3. 설정 호환에서 **"없음"과 "빈 값"은 다르다**. 필드가 아예 없으면 옛 값을 가져오고, 빈 값이면 사용자의 뜻이다(`model_fields_set`).
