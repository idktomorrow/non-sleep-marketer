# 2026-10-27 배치 E1: 오류 종류 표와 실패 증거

## 목표

흩어진 실패 처리(재시도 15·60·240분 후 포기, 429 쉬기, 로그인 풀림 멈춤, 분류기 대체, 중단 복구)를 "오류 종류 표" 하나 밑으로 모으고, 어댑터가 실패하는 순간의 화면을 자동으로 남긴다. 새 자가 치유는 만들지 않는다. 기존 동작은 바꾸지 않되 화면 변경만 재시도하지 않는다(사용자 지시).

## 한 일

- `nsm/domain/errors.py`: `ErrorKind` 5종(transient·rate_limited·auth·ui_changed·config_or_bug)과 종류별 정책(재시도 방식, health 실패 시 멈춤, 알림, 사람에게, 증거). `kind_of(e)`·`policy_for(e)`.
- `aside_common.PlatformError(kind=…)`: 포트의 `AdapterError`는 동결이라 하위 클래스에 속성으로. `LoginRequiredError`·`AccountMismatchError`(auth, 계정 미설정은 config_or_bug)·`RateLimitedError`(rate_limited)도 그 아래. Aside 오류 코드 → 종류 대응표(`kind_for_code`), 인스타그램·스레드의 파이썬 쪽 `raise`는 config_or_bug.
- 증거: Aside 스크립트의 `catch`에서 탭을 닫기 전에 화면(base64)·대화상자 수·보이는 글·svg title/aria-label·주소를 모아 결과로 보내고, 어댑터가 `logs/shots/<플랫폼>-<시각>/`에 저장(`nsm/adapters/evidence.py`). 오류 문구 끝에 `(증거: 폴더)`. 비밀처럼 보이는 값(토큰·키·세션·Bearer, 주소 쿼리)은 지운다. 저장 실패는 경고만.
- 엔진: 게시(`_record_failure`가 표를 읽어 화면 변경은 바로 포기·검토·알림), 답글(요청 제한만 쉬고 나머지는 사람에게 — 그대로), health(요청 제한은 쉬기, 그 밖은 멈춤 — 그대로). 정리 잡이 `evidence_keep_days`(14) 넘은 폴더를 지운다.
- 테스트에서 실제 `~/.nsm/logs/shots`를 건드리지 않게 autouse 픽스처로 증거 폴더를 임시 폴더로.
- ADR 0054, architecture 6-1절 표·구현 상태, 설명서(설정표·문제 해결 "증거 폴더 여는 법"), CHANGELOG. 버전 0.4.10.

## 막힌 것과 해결

- **포트 동결.** 사용자는 "AdapterError에 kind를 붙여라"였지만 `nsm/ports`는 두 사람 합의 없이 못 바꾼다. ADR 0038이 `retry_at`을 속성으로 읽은 선례를 따라 어댑터 쪽 하위 클래스에 `kind`를 두고 엔진은 `getattr`로 읽었다. 포트 파일은 한 글자도 안 바뀌었다.
- **스크린샷 타이밍.** 파이썬이 오류를 받을 때는 이미 `finally`가 탭을 닫았다. 증거 수집을 스크립트의 `catch` 안으로 넣어 닫기 전에 찍고, 결과 JSON에 실어 보냈다(남은 시간 예산 안에서 최대 8초).
- **`script`가 다 화면 변경은 아니다.** `waitFor` 시간 초과도 `script`로 온다. 느린 페이지일 수 있어 그건 transient로 남겨 지금처럼 재시도한다.
- **비밀 지우기가 샜다.** `token=…&page=2`에서 `\S+`가 뒤의 쿼리까지 먹고, `Bearer xyz`는 두 낱말이라 남았다. 값 패턴을 `[^\s&;,"']+`로 좁히고 Bearer를 따로 처리. 테스트가 잡았다.
- **테스트가 실제 홈을 건드릴 뻔.** 정리 잡 테스트가 실제 `~/.nsm/logs/shots`를 지울 수 있었다(테스트 기본 NSM_HOME 격리가 없음). autouse 픽스처로 막았다.

## 배운 것 (신입 개발자용)

1. **오류는 "무슨 일이 났나"보다 "다시 하면 달라지나"로 나눈다.** 일시적이면 기다렸다 다시, 화면이 바뀌었으면 몇 번을 해도 같다. 이 한 질문이 재시도 정책을 정한다.
2. **증거는 실패한 그 순간에만 있다.** 탭이 닫히고 나면 같은 화면을 다시 볼 수 없다. 정리 코드(`finally`)보다 먼저 남기는 자리를 찾아야 한다.
3. **자동화의 경계는 "되돌릴 수 있나"로 긋는다.** 재시도·쉬기·사람에게 넘기기는 되돌릴 수 있지만, 게시와 답글은 아니다. 되돌릴 수 없는 동작 앞에서는 코드가 추측해서 고치지 않고 멈춘다.
