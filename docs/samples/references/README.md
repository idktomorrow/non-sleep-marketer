# 카드 스타일 레퍼런스 (S8 #34)

> 수집: 2026-10-14 (배치 S8) · 관련: [ADR 0036](../../adr/0036-code-drawn-card-styles.md), 결과 샘플은 [docs/samples/styles/](../styles/)

인스타그램 카드뉴스 중 사진형·일러스트형을 골라, 우리 스타일에 **무엇을 가져올지**만 적는다. 저작권 때문에 이미지는 저장소에 넣지 않고 링크만 남긴다. 1~3번은 2026-10-14에 각 계정의 최근 게시물을 브라우저로 직접 열어 확인했다(읽기 전용).

우리 쪽 제약도 함께 적는다.

- 사진 대신 코드로 그린 배경(그라디언트·도형·SVG)을 쓴다. AI 배경 이미지는 유료라 기본으로 꺼 두었다(ADR 0036).
- 글자는 이미지에 굽지 않고 HTML로 올린다.
- 가상인물·광고 표기와 S-γ 표지 가독성(부제 60px, 제목 최소 88px)은 스타일과 무관하게 지킨다.

## 정리: 스타일별로 가져온 것

- **photo:** 주 색을 아주 어둡게 깐 꽉 찬 배경, 고리·사선 띠·점 무늬 도형, 아래쪽 어둡게, 형광펜 상자 제목, 흰 말풍선(부제·본문 문단·마무리 문구).
  - 배경 사진이 있는 장은 사진을 쓴다(직접 올린 사진, 또는 켜 둔 경우 AI 배경).
- **illust:** 파스텔 + 점 무늬 바탕, 모서리 얼룩 두 개, 표지·마무리의 언덕과 페르소나 캐릭터, 본문 장 위 띠의 작은 캐릭터, 흰 스티커 번호 카드, 테두리 말풍선.
- **공통으로 안 하는 것:** 카드 아래 "더 알아보기" 같은 CTA 띠. 인스타그램 광고의 플랫폼 기능이라 이미지에 그리지 않는다.
