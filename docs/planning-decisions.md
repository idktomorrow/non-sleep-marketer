## 최종 확정안

### Context
누구나 자기 PC에 설치해서 쓰는 로컬 프로세스입니다. 사용자가 자기 브랜드와 "AI 가상 인플루언서" 페르소나를 설정하면, 프로세스가 다음을 합니다.
- 자료를 모아 분류하고 카드뉴스를 만듭니다.
- 인스타그램·스레드·네이버 블로그에 게시합니다.
- 내 게시물에 달린 댓글에 대댓글을 달고, 결과를 대시보드로 모아 보여줍니다.

팀은 2명이고 일정은 2주 이내(빠를수록 좋음)입니다.

### 확정된 결정
| 영역 | 결정 |
|---|---|
| 형태 | 사용자마다 자기 PC에 설치. 설정 파일과 API 키도 각자 넣음. 처음 실행할 때 설정 마법사로 생성 |
| 페르소나 | 사용자가 직접 설정(YAML: 브랜드, 인물상, 말투, 금칙어·금칙 패턴, 관심 주제, 활동 시간, on/off). 게시물 첫 줄에 가상인물 문구, 카드마다 "가상인물" 배지 (Round 4에서 문구 구체화) |
| 광고 | 협찬·브랜디드 콘텐츠로 수익화. "광고" 표기 자동 삽입(켜기/끄기). 협찬 관리 기능은 이후로 미룸 |
| 수집 | 직접 올리는 자료 + 네이버 + 구글 트렌드는 필수, 커뮤니티는 선택 체크. 수집은 **Aside 브라우저**로 하고 **jev**가 관련성과 주제를 분류 |
| 콘텐츠 | AI가 배경·일러스트를 만들고, 글자는 HTML 템플릿(정보형·리스트형·**비교형**)으로 얹어 Playwright로 PNG 생성. 블로그용 긴 글은 Claude API로 작성. 후기형은 공정위 지침 위험으로 제외(Round 4) |
| 게시·대댓글 | **Aside 브라우저**로 인스타그램·스레드·네이버 블로그에 게시(MVP부터 세 플랫폼 모두). Meta 개발자 등록은 하지 않고, Cloudinary 호스팅도 필요 없음 |
| 자동/검토 | 모든 사실 주장(claim)에 출처가 연결되고 자료 관련성 신뢰도가 0.8 이상이며 금칙어가 없으면 자동 게시, 아니면 사유와 함께 검토 대기열. 설치 후 첫 20건은 보호 모드로 전부 검토(Round 4). 댓글은 6가지로 분류해 칭찬·질문은 자동 답글, 스팸은 숨김(미지원 플랫폼은 사람에게), 나머지는 사람에게 넘김. 같은 사람에게는 하루 3번까지만 자동 답글 |
| 한도 | 플랫폼별 일일 게시 쿼터(기본 인스타 1·스레드 2·블로그 1), 일일 비용 상한(기본 $3), 최근 14일 주제 중복 제외, URL 중복 수집 제외 (Round 4) |
| 대시보드 | **FastAPI + Jinja2/HTMX** 로컬 웹 대시보드를 엔진과 같은 프로세스에서 띄움(Round 4, Streamlit 폐기). 콘텐츠 성과, 팔로워, 대댓글 처리 현황, 비용, 주간 결산 표시 + 검토 대기열·페르소나·자동 게시 토글. 성과 수치는 어댑터가 각 플랫폼의 인사이트 화면을 읽어서 가져옴 |
| 실행 | 로컬 PC를 계속 켜두는 **단일 프로세스**(`nsm run`). 주기가 다른 잡 7개(상태 점검 30분, 수집 2회/일, 생성 1회/일, 게시 슬롯, 댓글 10분, 지표 1회/일, 주간 결산). Windows 작업 스케줄러로 자동 시작 (Round 4) |
| 개발 순서 | 드라이런 모드부터: 실제로 게시하지 않고 미리보기 파일로 저장. 약 1주 MVP를 만든 뒤 실제 계정 연결(스레드 → 인스타그램 → 네이버) |
| 스택 | Python 3.12, uv, Claude SDK, DuckDB(로컬, 무료) + MotherDuck(jev 호출), Playwright, FastAPI, APScheduler, keyring, winotify, Aside CLI |
| 테스트 경계 | 엔진 잡 1회 실행(가짜 포트) + 플랫폼 어댑터 계약 테스트(드라이런은 기본 실행, 실계정은 별도 마커) + 템플릿 렌더 테스트 + 대시보드 라우트 테스트 |
| 역할 | 메인(선웅제): 제품 전부 + 마지막 UI/UX 디자인. 서브(팀원): 테스트 전부 + 카드뉴스 템플릿·렌더러. 세부는 [issues.md](issues.md) |

### 위험 요소와 대응
- **계정 제재**: 네이버·커뮤니티·Meta 모두 약관에서 자동화 수단 사용을 제한합니다. 다음과 같이 대응합니다.
  - 활동 빈도를 낮추고, 시간 간격에 무작위 지연을 넣습니다.
  - 원문을 복사하지 않고 사실만 요약해 출처를 붙입니다.
  - 수집 전용 계정을 따로 씁니다.
  - 사용자에게 위험을 고지하는 동의 화면을 넣습니다.
- **Aside가 사람 없이 동작하는지**: 게시처럼 민감한 행동에 사용자 승인을 요구한다는 소개가 있습니다. **1일차에 직접 확인**하고, 막히면 로그인 상태를 저장한 Playwright 브라우저 프로필로 대신합니다. 게시 모듈은 갈아끼울 수 있게 인터페이스로 분리해 둡니다.
- **jev 사용**: 초대가 아니라 MotherDuck 계정(Lite 플랜, 현재 $0)으로 씁니다. 1일차에 `prompt_jev` 호출을 확인하고, 안 되면 같은 포트의 Claude 분류기를 기본으로 씁니다.
- **공정위 지침(2026-06-01, 계도기간 없음)**: 가상인물 표시를 해도 실제 체험 기반 추천처럼 쓰면 부당 광고. 후기형 제외, 1인칭 체험 표현을 금칙 패턴으로 차단. 원문 대조는 1일차 항목.
- **DuckDB 단일 프로세스 제약**: 엔진·대시보드를 한 프로세스에 둬서 해결.

### 모듈 구성 (2명 분담)
- **메인(선웅제)**: 설정·마법사, 수집 소스, 분류기, 생성기, 정책·엔진 잡, 저장소, 드라이런·실계정 어댑터, 대댓글, 대시보드 백엔드, 스케줄러·운영, 지표·주간 리포트, 마지막 UI/UX 디자인
- **서브(팀원)**: 테스트 기반(fakes·픽스처·CI), 카드뉴스 템플릿 3종, 렌더러·미리보기 하네스, 엔진 시나리오 테스트, 어댑터 계약 테스트, 대시보드 라우트 테스트, 2주차 품질 점검
- 디렉터리 소유권과 인터페이스는 [contracts.md](contracts.md)

### 일정 (빠를수록 좋음)
- 1일차: 저장소 골격 → 계약 동결(포트·모델·스키마·카드 덱) → 기술 검증(Aside 무인, MotherDuck jev, 댓글 숨기기 메뉴, 프로 계정, 네이버 에디터 탐색, 법규 원문)
- 2~5일차: 드라이런 기준으로 전체 흐름 완성 (설정, 저장소, 수집, 분류, 생성, 정책·잡, 드라이런 어댑터) / 서브: 템플릿·렌더러·엔진 테스트
- 6~7일차: 대시보드 백엔드, 대댓글, 스케줄러·운영 → **드라이런 MVP 완성**
- 8~12일차: 실제 계정 어댑터(스레드 → 인스타그램 → 네이버), 계약 테스트
- 11~14일차: 지표·주간 리포트, UI/UX 디자인 패스, 회귀 테스트

## 조사 메모
- **jev**: TypeSafe의 분류 전용 모델입니다. 글을 생성하지 않고, 정해진 선택지 중 하나를 신뢰도와 함께 돌려줍니다. MotherDuck에서 SQL `prompt_jev()`로 호출하고, 대량 분류에 빠르고 저렴합니다.
- **AI 기본법(2026.1.22 시행) 제31조**: 투명성 의무가 있습니다. 공정위 추천·보증 지침에는 가상인물 표시 기준이 있습니다. → 게시물마다 AI·광고 표기를 자동으로 넣습니다.
- **네이버 검색 API**: 2026-09-07 약관 개정으로 검색 결과를 AI 요약·학습에 쓰는 것과 저장이 금지됐다고 보도됐습니다. API를 쓸 때만 적용되므로 Aside로 수집하는 방식과는 무관합니다.
- **서비스 이용약관**: 네이버와 커뮤니티의 서비스 이용약관은 수집 도구와 상관없이 매크로·봇 같은 자동화 수단 사용을 제한합니다. 매크로로 카페·블로그를 자동 이용한 판례도 있습니다.
- **Aside**: Aside Computer(YC 투자)가 만든 크로미움 기반 AI 브라우저입니다. 로그인된 사이트에서 직접 작업하고, CLI로 Claude Code와 연동할 수 있습니다. 결제·게시·메시지 전송은 사용자 승인을 기다리도록 설계됐다는 소개가 있습니다. 2026년 9월 윈도우판이 출시됐습니다.
- **이미지 생성 API**: Google과 OpenAI 모두 API 무료 티어가 없습니다. 가격은 장당 약 $0.02(Imagen 4 Fast)에서 $0.134(Gemini 3 Pro Image) 사이입니다. AI가 이미지 안에 그린 한글은 품질을 보장할 수 없습니다.
- **참고(최종안에서는 쓰지 않음)**:
  - Instagram Graph API와 Threads API의 게시·답글 한도, Meta 개발 모드는 테스터 최대 50명
  - Cloudinary 무료 플랜은 매달 25크레딧
