# 원고 품질 체크리스트 (수동 점검)

> 작성: 2026-10-14 (배치 S-γ, 이슈 #23) · 관련: [사용설명서](user-guide.md) 8절, [ADR 0019](adr/0019-label-wording-and-placement.md) 표기, [ADR 0023](adr/0023-code-checked-content-rules.md) 자동 검사

코드가 자동으로 막는 것도 있습니다. 금칙어, 표기 문구, 지난 일정을 "예정"으로 쓰기, 소문, 어색한 마무리 문구가 그렇습니다. 사람 눈으로만 볼 수 있는 것은 이 목록으로 확인합니다.

- **언제:** 처음 10건(보호 모드)은 승인 전에 원고마다 확인합니다. 그 뒤에는 주 1회, 게시된 글 3개를 골라 확인합니다.
- **어디서:** 대시보드(`uv run nsm run` 실행 중 http://127.0.0.1:8765)
  - 검토 → 원고 하나를 열기: 카드 이미지, 올릴 글, 사실 주장과 출처, 게시 상태를 한 화면에서 봅니다.
  - 게시 대기: 승인된 원고를 같은 화면으로 열 수 있습니다.
  - 올라간 글: 게시 상태 표의 "열기"로 실제 글을 엽니다.

## 1. 말투 일관성

- [ ] **페르소나 말투와 같다**
  - 설정 → 페르소나의 "말투"를 먼저 읽습니다.
  - 검토 → 원고 열기 → "올릴 글"의 인스타그램·스레드 본문이 그 말투인지 봅니다(존댓말·반말, 이모지 양).
- [ ] **카드와 본문의 말투가 같다**
  - 원고 화면 왼쪽 카드 이미지(제목·본문 장)와 오른쪽 "올릴 글"을 나란히 읽습니다. 한쪽만 딱딱한 보도문체면 고칩니다.
- [ ] **최근 글들과 말투가 크게 다르지 않다**
  - 게시 대기 → 아래 "최근 7일 게시"에서 지난 글 2~3개를 열어 지금 원고와 비교합니다.
- [ ] **마무리 문구가 자연스러운 질문·말 걸기다**
  - 카드 마지막 장을 봅니다. 예: "여러분은 보셨나요?"
  - "링크는 저장부터" 같은 지시는 코드가 막지만, 주제와 동떨어진 질문은 사람이 봐야 합니다.

## 2. 출처 정확성

- [ ] **사실 주장마다 출처가 있다**
  - 원고 화면 → "사실 주장과 출처": 주장 한 줄마다 오른쪽에 자료 ID(← 01M…)가 붙어 있어야 합니다.
- [ ] **출처 링크를 열면 그 내용이 실제로 있다**
  - 같은 칸 아래 출처 링크를 눌러 기사·글을 엽니다.
  - 날짜, 숫자(관객 수·순위), 이름이 원고와 같은지 2개 이상 대조합니다.
- [ ] **오래된 자료가 아니다**
  - 기사 날짜가 오늘 기준 1주 안인지 봅니다(자료 수집 기간 설정).
  - 이미 지난 행사를 "예정"으로 쓰지 않았는지 봅니다.
- [ ] **카드 마지막 장의 출처가 사이트 이름으로 보인다**
  - 카드 마지막 장 "출처" 아래가 연합뉴스·아이즈처럼 사이트 이름이어야 합니다.
  - 목록에 없는 사이트는 `finomy.com`처럼 짧은 주소로 나옵니다.
- [ ] **글 끝 "출처:" 줄이 있다**
  - "올릴 글"의 스레드·인스타그램 본문 끝에 `출처: 연합뉴스, 아이즈` 같은 줄이 있는지 봅니다.
- [ ] **올린 파일이 출처면 그 파일 내용과 맞다**
  - 자료 → "올린 파일"에서 그 파일의 "쓰인 원고"를 확인합니다.

## 3. 표기 위치 (가상인물 · 광고 · AI 생성)

- [ ] **가상인물 문구가 글 맨 앞에 있다**
  - "올릴 글"의 인스타그램·스레드 본문 첫 줄이 정확히 `인공지능(AI)을 기반으로 생성된 가상인물이 포함된 게시물입니다`인지 봅니다.
- [ ] **가상인물 배지가 모든 카드에서 페르소나 이름 바로 옆에 있다**
  - 카드 이미지 왼쪽 위 "이름 @계정 [가상인물]"을 1장부터 마지막 장까지 넘겨 봅니다.
- [ ] **인스타그램에서 배지가 잘리지 않았다**
  - 게시 상태 → 인스타그램 "열기"로 실제 글을 엽니다.
  - 카드가 세로(4:5)이고 위쪽 배지가 보이는지 봅니다. 1:1로 잘렸으면 배지가 사라집니다.
- [ ] **광고면 "광고" 배지와 `#광고`가 있다** (설정 → 운영의 "광고" 표기를 켠 경우)
  - 카드 첫 장 오른쪽 위에 주황 "광고" 배지가 있는지 봅니다.
  - 본문 앞부분에 `#광고`가 있는지 봅니다.
- [ ] **배경 이미지를 쓴 장에는 "AI 생성 이미지"가 있다**
  - 배경 사진이 깔린 장의 왼쪽 아래 작은 글씨를 봅니다. 배경이 없는 장(단색 그라디언트)에는 없어야 정상입니다.

## 4. 한글 깨짐

- [ ] **카드에 □, ?, 깨진 글자가 없다**
  - 원고 화면 카드 이미지를 장마다 브라우저 확대(Ctrl + +)로 크게 봅니다. 특히 이모지·특수문자(～, ·, ‘ ’) 주변을 봅니다.
- [ ] **글자가 칸 밖으로 넘치거나 잘리지 않았다**
  - "미리보기 렌더"를 누르면 넘치는 장이 있을 때 "N장에 글이 넘칩니다" 경고가 나옵니다.
  - 경고가 없어도 마지막 줄이 잘렸는지 눈으로 봅니다.
- [ ] **실제 글에서 줄바꿈·이모지가 깨지지 않았다**
  - 게시 상태 → "열기"로 스레드·인스타그램 글을 열어 줄바꿈이 대시보드 "올릴 글"과 같은지 봅니다.
- [ ] **표지 제목 줄 사이가 지나치게 벌어지지 않았다**
  - 제목에 빈 줄이 들어와도 한 줄바꿈으로 그리지만(S-γ), 이상하면 원고에서 제목 줄을 고칩니다.

## 5. 스레드 썸네일 가독성

스레드 피드는 카드 첫 장을 약 224×280 픽셀로 작게 보여 줍니다(원본의 21%, 2026-10-14 실측).

- [ ] **휴대폰 피드에서 첫 장 제목이 읽힌다**
  - 휴대폰 스레드 앱 → 내 프로필(@계정) → 방금 올린 글의 첫 장을 확대하지 않고 봅니다.
  - 제목은 바로 읽혀야 합니다. 부제는 조금 집중하면 읽히면 됩니다.
- [ ] **제목이 3줄 이하다**
  - 원고 화면 카드 첫 장에서 제목이 4줄 이상이면 글자가 작아집니다. 검토 → 원고 열기 → 카드 문구에서 표지 제목을 짧게 줄입니다.
- [ ] **가상인물 배지가 썸네일에서도 흰 알약 모양으로 보인다**
  - 글자가 다 읽히지 않아도 위치와 모양은 보여야 합니다. 본문 첫 줄의 가상인물 문구가 함께 있으므로 둘 다 확인합니다.
- [ ] **PC에서 한 번에 확인하기**
  - 원고 화면 카드 이미지를 브라우저 축소(Ctrl + -)로 25% 크기로 줄여 봅니다. 스레드 썸네일과 비슷한 크기입니다.

## 6. 릴리스 전 회귀 테스트 (개발자용, 명령 그대로)

PowerShell에서 저장소 폴더로 이동한 뒤 위에서부터 차례로 실행합니다. 실행 중인 `nsm run`이 있으면 DB를 잡고 있으므로 먼저 끕니다(Ctrl+C). 실계정 테스트(5~6번)는 Aside 브라우저에 스레드·인스타그램이 로그인돼 있어야 합니다.

```powershell
# 1) 코드 스타일
uv run ruff check .
uv run ruff format --check .

# 2) 기본 테스트 전체(엔진·대시보드·렌더·드라이런 계약 포함, 실계정 제외)
uv run pytest

# 3) 카드 렌더(썸네일 가독성·표기 슬롯·넘침 회귀)만 따로
uv run pytest tests/render

# 4) 어댑터 계약(드라이런 + 실계정 어댑터 약속, 실계정 접속 없음)
uv run pytest tests/contracts/test_platform_contract.py

# 5) 실계정 읽기 전용 점검(로그인 계정·팔로워·기존 글 지표, 글을 올리지 않음)
$env:NSM_CONTRACT_THREADS_POST = "<스레드 글 코드>"; $env:NSM_CONTRACT_INSTAGRAM_POST = "<인스타그램 글 코드>"
uv run pytest -m contract tests/contracts/test_platform_contract.py

# 6) 실계정 게시·삭제 계약(운영 계정에 [계약 테스트] 글을 올렸다가 지움. 사람이 있을 때만)
uv run pytest -m contract

# 7) 환경 점검과 카드 미리보기
uv run nsm doctor
uv run nsm render-preview tests/fixtures/decks/info.json
```

- 6번이 끝나면 스레드·인스타그램 프로필에 "[계약 테스트]" 글이 남지 않았는지 확인합니다.
- 7번 미리보기 PNG(`%USERPROFILE%\.nsm\preview\render`)를 열어 1~5절 중 3·4·5절을 눈으로 봅니다.
